# Тесты стандартной библиотеки ZIP

| Файл | Модуль | Что проверяет |
|------|--------|---------------|
| `тест_ядро.zip` | ядро | модуль, минимум, максимум |
| `тест_тензоры.zip` | тензоры | создать / заполнить / сложить |
| `тест_нейросети.zip` | нейросети | релу, создать_слой |
| `тест_сеть.zip` | сеть | разобрать_url |
| `тест_крипто.zip` | крипто | sha256 (размер дайджеста) |

Запуск (когда линковка STD готова):

```
zipc zip-std/тесты/тест_ядро.zip -o /tmp/t_ядро
```
