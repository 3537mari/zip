# Интерактивный курс ZIP

Полный курс «ZIP за 30 минут» — 8 уроков с интерактивным плейграундом.

**Онлайн:** https://3537mari.github.io/zip/курс/

## Как использовать

1. Откройте `index.html` в браузере (или страницу на GitHub Pages)
2. Проходите уроки последовательно
3. Запускайте код прямо в браузере (WASM)
4. Решайте задачи и отмечайте прогресс (сохраняется в `localStorage`)

## Список уроков

1. Введение — 3 мин
2. Переменные — 3 мин
3. Функции — 4 мин
4. Условия и циклы — 4 мин
5. Массивы — 3 мин
6. Аннотации — 4 мин
7. Нейросети — 5 мин
8. Агенты — 4 мин

**Итого: 30 минут**

## Файлы

- `style.css` — стили, мобильная адаптация, тёмная тема
- `script.js` — WASM / fallback
- `progress.js` — прогресс уроков
- `checker.js` — проверка задач
