# ZIP (Zero-Immunity-Pulse)

Язык программирования для ИИ-агентов и нейросетей.

## Назначение

ZIP предназначен для написания ИИ-агентов и нейросетевых систем: потоковая обработка событий, цепочки действий и явное разделение живого процесса и зафиксированного результата.

## Алфавит

Исходный код пишется **только русскими буквами**.

## Архитектура

Парадигма исполнения — **VSO** (Глагол–Субъект–Объект): каждая инструкция начинается с действия, за которым следуют субъект и объект.

## Компиляция

Компилятор ZIP собирается через **самокомпиляцию (bootstrapping)**: ранний этап (`bootstrap/`) поднимает минимальный компилятор, далее язык компилирует сам себя.

## Структура репозитория

| Каталог | Назначение |
|---------|------------|
| `bootstrap/` | Начальный компилятор для самосборки |
| `zipc/` | Компилятор ZIP |
| `zip-vm/` | Виртуальная машина |
| `zip-std/` | Стандартная библиотека |
| `examples/` | Примеры программ |
| `tests/` | Тесты |
| `docs/` | Документация |
| `scripts/` | Вспомогательные скрипты |
