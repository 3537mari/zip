Урок 2: Переменные

Присваивание через =. Типы выводятся из литералов.

функция главная() {
    а = 42
    имя = "ZIP"
    ПечатьЧисло(а)
    ПечатьСтроки(имя)
}

Частые типы: целое, вещественное, строка, флаг (истина/ложь).
