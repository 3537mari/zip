# ZIP — Zero-Immunity-Pulse

**Кириллический самокомпилируемый язык программирования.**

## Быстрый старт

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
./zipc/target/release/zipc запустить examples/привет.zip
```

## Возможности

- Скорость LLVM / Rust-бутстрэп
- Постквантовая криптография и анализ владения
- ИИ-примитивы (тензоры, нейросети)
- Самокомпиляция (fixed point)
- Кириллический синтаксис VSO
