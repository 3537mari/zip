## Требования

- Rust 1.75+
- LLVM 17+ (`clang` в PATH)
- PowerShell 7+ на Windows

## Сборка

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
cargo build --release --manifest-path зипм/Cargo.toml
```

Добавьте `zipc/target/release` и `зипм/target/release` в `PATH`.
