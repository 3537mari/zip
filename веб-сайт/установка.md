# Установка ZIP

## Требования

- Rust 1.75+
- LLVM 17+ (`clang` в PATH)
- Git
- PowerShell 7+ на Windows (рекомендуется)

## Быстрая установка

### Linux / macOS

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
export PATH="$PWD/zipc/target/release:$PWD/zip-vm/target/release:$PATH"
```

### Windows

```powershell
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
$env:PATH += ";$PWD\zipc\target\release;$PWD\zip-vm\target\release"
```

Опционально пакетный менеджер:

```bash
cargo build --release --manifest-path зипм/Cargo.toml
```

## Проверка

```bash
zipc --help
zipc запустить examples/привет.zip
```

## Первая программа

```bash
cat > привет.zip << 'EOF'
ПечатьСтроки("Привет, мир!")
EOF

zipc запустить привет.zip
```
