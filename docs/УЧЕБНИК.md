## Установка

### Требования

- Rust 1.75+
- LLVM 17+ (`clang` в `PATH`)
- Git

### Сборка

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
```

Добавьте в `PATH`:

```bash
# Linux / macOS
export PATH="$PWD/zipc/target/release:$PATH"

# Windows (PowerShell)
$env:PATH = "$PWD\zipc\target\release;$env:PATH"
```

Проверка:

```bash
zipc версия
# zipc 0.1.0  (релиз языка — v1.0.0)
```

## Первая программа

Создайте файл `привет.zip`:

```zip
печать_строки("Привет, мир!")
```

Запустите:

```bash
zipc запустить привет.zip --llvm
# Привет, мир!
```

Поздравляем — первая программа на ZIP готова.

## Переменные и типы

Идентификаторы — только кириллица:

```zip
функция главная() {
    // Целые числа
    возраст = 25

    // Вещественные
    температура = 36.6

    // Строки
    имя = "Иван"

    печать_число(возраст)
    печать_число(температура)
    печать_строки(имя)
}
```

Типы часто выводятся; для коллекций и «корневых» буферов используются шаблоны вроде `СИПРА` (см. [Корни](#корни-и-глаголы)).

## Функции

```zip
функция сложить(а, б) {
    возврат(а + б)
}

функция главная() {
    результат = сложить(2, 3)
    печать_число(результат)  // 5
}
```

Аннотации:

```zip
@ускорить(уровень = 3)
@кэшировать(размер = 1024)
функция дорогая(х) {
    возврат(х * х)
}
```

## Условия и циклы

### Условие

```zip
если (возраст >= 18) {
    печать_строки("Взрослый")
} иначе {
    печать_строки("Ребёнок")
}
```

### Цикл «для»

```zip
для и в 0..10 {
    печать_число(и)  // 0 … 9
}
```

### Цикл «пока»

```zip
счётчик = 0
пока (счётчик < 5) {
    печать_число(счётчик)
    счётчик = счётчик + 1
}
```

### Итерация по буферу

```zip
числа = СИПРА(5)
СИПРА_добавить(числа, 10)
СИПРА_добавить(числа, 20)

для число в СЫПРА_из_СИПРА(числа) {
    печать_число(число)
}
```

## Корни и глаголы

**Корни** — трёхбуквенные семантические ядра, например:

| Корень | Смысл |
|--------|--------|
| СПР | счёт, вычисления |
| ЧТВ | память |
| ЖВТ | жизнь, создание |

Глаголы и типы строятся шаблонами гласных:

```zip
СПР = {
    А-А: САПАР,    // глагол: считать
    И-А: СИПРА,    // буфер / множество
    О-О: СПОРО     // инструмент
}
```

Комплементарный корень создаётся автоматически:

```zip
СПР = { А-А: САПАР }  // ↔ РПС = { А-А: РАПАС }
```

Подробнее: [Справочник — корни](СПРАВОЧНИК.md#корни-и-шаблоны).

## Аннотации

Встроенные аннотации (неполный список — см. [справочник](СПРАВОЧНИК.md#аннотации)):

```zip
@пластичность(порог = 1000)      // авто-оптимизация горячих путей
@comptime                         // вычисления при компиляции
@ускорить(уровень = 3)            // агрессивная оптимизация
@кэшировать(размер = 1024)        // кэш результатов
@шифровать(алгоритм = "AES-GCM")  // шифрование
@параллелить(потоков = 4)         // автопараллелизм
@сон(интервал = "5m")             // авто-прунинг
@тест(случай = 100)               // автогенерация тестов
@нейрогенез(порог = 5)            // композиты из паттернов IR
```

## Нейросети на ZIP

```zip
// Слои
слой1 = создать_слой(2, 4)
слой2 = создать_слой(4, 1)

вход = создать_тензор(1, 2, 0, 0)
заполнить_тензор(вход, 2, 1, 0.5)

h = прямой_проход_слоя(слой1, вход)
выход = прямой_проход_слоя(слой2, h)

печать_число(выход)
```

Пример обучения XOR: `zip-std/примеры/` — порядка десятков миллисекунд на типичном CPU.

Подробнее: [STD — нейросети](STD.md#нейросети-нейросетиzip).

## Агенты и потоки

### Поток данных

```zip
поток обработка {
    источник = ВАДАТ(камера)
    фильтр размытие = САПАР(фильтр_размытия)
    фильтр края = САПАР(детектор_краёв)
    приёмник = ЧАТАВ(результат)
}
```

### Агент с состоянием

```zip
агент Счётчик {
    состояние {
        всего: Целое = 0
    }

    функция увеличить() {
        всего = всего + 1
    }
}

функция главная() {
    счётчик = создать_Счётчик()
    счётчик.увеличить()
    счётчик.увеличить()
    печать_число(счётчик.всего)  // 2
}
```
