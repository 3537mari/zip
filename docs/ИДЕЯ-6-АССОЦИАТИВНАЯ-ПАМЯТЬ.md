# Идея 6. Ассоциативная память

## Основание

Мозг хранит понятия как сеть ассоциаций. В ZIP это позволяет
умное автодополнение и поиск по смыслу.

## Типы связей

| Иконка | Тип | Смысл |
|--------|-----|--------|
| 🔗 | **Ассоциация** | семантическая связь |
| ⚔️ | **Противоположность** | обратное |
| → | **Следствие** | что следует |
| ← | **Причина** | что предшествует |
| 📁 | **Категория** | к чему относится |
| 🌐 | **Аналог** | в других языках |

## Использование в LSP

При наборе кода LSP показывает:

1. Автодополнение с ассоциациями (рядом с текущим словом)
2. Hover с описанием и связями
3. Команды VSCode:
   - **ZIP: Показать ассоциации** — webview для слова под курсором
   - **ZIP: Визуализировать граф** — полный граф

## Пример

При работе с `СПР`:

- САПАР, СИПРА, СПОРО — ассоциации
- РПС — противоположность
- тензоры, нейросети — связанные понятия
- математика — категория

```zip
СПР = { А-А: САПАР, И-А: СИПРА }
данные = СИПРА(10)
результат = САПАР(данные) >> ЧАТАВ!
```

## API

Модуль `zipc::ассоциации`:

- `ГрафАссоциаций::новый()` — стандартный граф ZIP
- `ассоциации(имя)` / `ассоциации_по_типу` / `по_категории` / `соседи`
- LSP-команды: `zip.associations`, `zip.graph`
