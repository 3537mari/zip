# ЗИПМ — менеджер пакетов ZIP

`зипм` (ZIP Package Manager) — аналог Cargo / npm / pip для экосистемы ZIP.

## Команды

| Команда | Alias | Описание |
|---------|-------|----------|
| `создать <имя>` | `create` | Новый пакет (каталоги + манифест) |
| `собрать` | `build` | Сборка через `zipc` / `selfc` |
| `установить` | `install` | Установить зависимости из манифеста |
| `добавить <имя> [версия]` | `add` | Добавить зависимость |
| `удалить <имя>` | `remove` | Удалить зависимость |
| `опубликовать` | `publish` | Опубликовать в реестр |
| `обновить` | `update` | Обновить зависимости |
| `запустить [путь]` | `run` | Запустить собранную программу |
| `тест` | `test` | Запустить тесты из `tests/` |
| `очистить` | `clean` | Очистить `цель/` и кэш |
| `инфо <имя>` | `info` | Информация о пакете |

## Формат манифеста (`зипм.манифест`)

```toml
# Манифест пакета ZIP
имя = "моя_библиотека"
версия = "0.1.0"
автор = "Иван Иванов <ivan@example.com>"
лицензия = "MIT"
описание = "Краткое описание"

[зависимости]
тензоры = "1.0.0"
нейросети = "0.5.0"
сеть = "2.0.0"

[зависимости_разработки]
тесты = "0.3.0"

[сборка]
тип = "библиотека"   # или "программа"
точка_входа = "src/главная.zip"
выход = "цель/выпуск/программа"

[тесты]
каталог = "tests/"
```

## Расположение артефактов

```
пакет/
├── зипм.манифест
├── src/
│   └── главная.zip
├── tests/
├── examples/
├── зипм_пакеты/          # скачанные зависимости
└── цель/
    └── выпуск/
        └── программа[.exe]
```

## Реестр

Локальный реестр: `реестр/` в корне репозитория.

- Индекс: `реестр/index.toml`
- Пакеты: `реестр/пакеты/<имя>/<версия>/`
- Сервер (заготовка): `реестр/сервер/`

Переменные окружения:

- `ZIP_ROOT` — корень репозитория zip-lang
- `ЗИПМ_РЕЕСТР` / `ZIPM_REGISTRY` — URL или путь к реестру (по умолчанию `реестр/`)

## Сборка

`зипм` ищет компилятор в порядке:

1. `ZIP_ROOT/zipc/target/release/zipc[.exe]`
2. `ZIP_ROOT/zip-self/selfc[.exe]` / `selfc_v3`
3. `zipc` в `PATH`
