# Идея 19. ИИ-советник в компиляторе

## Основание

Компилятор как разумный помощник. Анализирует код и предлагает оптимизации.

## Использование

```bash
# Статистический анализ (без LLM)
zipc собрать программа.zip --ии-советник

# Через локальный Ollama
zipc собрать программа.zip --ии-советник --ии-провайдер ollama

# Через OpenAI
zipc собрать программа.zip --ии-советник --ии-провайдер openai \
    --ии-модель gpt-4o-mini
```

## Категории рекомендаций

- Оптимизация — ускорить код (`@пластичность`, `@нейрогенез`)
- Безопасность — добавить `@шифровать`
- Параллелизм — использовать `||`
- Кэширование — добавить `@кэшировать`
- Читаемость — упростить код

## Статистический анализ (без LLM)

Работает без интернета:

- Функции с большим числом вызовов → `@пластичность`
- Функции с «секретными» именами → `@шифровать`
- Асинхронные функции с блокировками → `||`
- Цепочки вызовов → `@нейрогенез`

## LLM-анализ

Через Ollama / OpenAI / Anthropic:

- Более глубокий анализ паттернов
- Специфичные для проекта рекомендации
- Генерация примеров кода

OpenAI/Anthropic в MVP используют статистический fallback (нужны API-ключи).

## JSON-вывод для CI

```bash
zipc собрать программа.zip --ии-советник --ии-вывод report.json
```

Формат:

```json
[
  {
    "функция": "дорогая_функция",
    "категория": "оптимизация",
    "описание": "...",
    "ожидаемый_прирост": 5.0
  }
]
```

## Флаги CLI

| Флаг | Алиас | Описание |
|------|-------|----------|
| `--ии-советник` | `--ai-advisor` | включить советник |
| `--ии-провайдер` | `--ai-provider` | `stat` / `ollama` / `openai` / `anthropic` |
| `--ии-модель` | `--ai-model` | имя модели |
| `--ии-вывод` | `--ai-output` | путь к JSON |

Демо: `examples/ии_советник_демо.zip`.
