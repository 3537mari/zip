# Отчёт о v4.0.0: Самодостаточность (Runtime + STD + Bootstrap-конвейер)

**Дата:** 2026-10-12

## Что достигнуто

### Runtime на ZIP
- Syscalls: `sys_read`, `sys_write`, `sys_open`, `sys_close`, `sys_mmap`, `sys_exit`
- Bump allocator, вывод, файлы — ZIP API + VM/C helpers

### STD на ZIP
- Ядро, тензоры, нейросети, крипто (`*_zip.zip` + `zip_std_v4`)
- JSON/CSV/RegEx/сеть — MVP-обёртки

### Bootstrap на ZIP (`zip-self-zip/`)
- Лексер / парсер / генератор / `главное.zip` — **конвейер на ZIP**
- `zip_self_compile` вызывает **тот же C-bootstrap** (детерминизм → fixed-point)
- Тест: `zip-self-zip/тесты/тест_fixed_point.ps1` / `.sh`, `tests/тест_self_zip.rs`

### Inline-asm
- `syscalls_inline` для x86-64 Linux; fallback на других ОС

## Установка / fixed-point

```bash
# Stage 0 — последний раз «снаружи»
./bootstrap/zipc zip-self-zip/главное.zip /tmp/selfc_v1.zipb

# Stage 1–2 — selfc компилирует себя
./zip-vm/target/release/zip-vm /tmp/selfc_v1.zipb \
  zip-self-zip/главное.zip /tmp/selfc_v2.zipb
sha256sum /tmp/selfc_v1.zipb /tmp/selfc_v2.zipb
# хеши совпадают
```

## Честные границы v4.0.0

| Компонент | ZIP-управление | Алгоритм без C/Rust |
|-----------|----------------|---------------------|
| Runtime syscalls | ✅ | частично (inline Linux) |
| STD | ✅ API | тяжёлое — VM builtins |
| Bootstrap lex/parse/codegen | ✅ API + CLI | движок = C-bootstrap |
| VM | каркас `zip-vm-zip` | Rust VM |

Полный порт лексера/парсера/генератора в чистый ZIP (без вызова C) и полная VM на ZIP — **v5**.
