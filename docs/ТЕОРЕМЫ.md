# Теоремы о ZIP

Формальные утверждения о ядре (байт-код v3 + Move + PERFECT).
Доказательства — на уровне инвариантов семантики; машинная проверка — zip-verify.

## Теорема 1 (Типовая безопасность)

**Утверждение.** Если программа P успешно проходит статическую проверку типов
(zip-verify --проверка типы), то при исполнении на ИсполнительV3 не возникает
ошибки несовместимости операндов арифметики/сравнений (в смысле модели типов).

**Доказательство (набросок).**

1. База: начальное состояние типизировано (пустой стек, регистры Ничто/параметры).
2. Шаг: каждое правило перехода из [ФОРМАЛЬНАЯ-СЕМАНТИКА.md](ФОРМАЛЬНАЯ-СЕМАНТИКА.md)
   сохраняет типизацию стека и регистров.
3. Индукция по длине трассы ⇒ все достижимые состояния типизированы.

**QED** (относительно модели типов zip-verify).

## Теорема 2 (Отсутствие гонок)

**Утверждение.** В программе с || (хор) при передаче данных только через >> (PULSE)
отсутствуют гонки данных на линейных значениях.

**Доказательство (набросок).**

1. Хор порождает независимые кадры/потоки с раздельными регистрами.
2. Общие данные передаются через Move (Pulse): источник обнуляется.
3. Следовательно, в любой момент существует не более одного живого владельца значения.
4. Гонка требует ≥2 одновременных записей/чтений-записей одного ресурса ⇒ невозможно.

**QED** (при соблюдении проверки владения).

## Теорема 3 (Инвариант PERFECT)

**Утверждение.** Если регистр зафиксирован через ! / PerfectLock, его содержимое
не перезаписывается до конца жизни кадра (без явного нарушения правил верификатора).

**Доказательство (набросок).**

1. PerfectLock(r) переводит R(r) в Совершенное(w).
2. Верификатор запрещает Store(r), если R(r) уже Совершенное.
3. Нет инструкции «записи внутрь» оболочки Совершенное.

**QED**.

## Теорема 4 (Самокомпиляция / fixed point)

**Утверждение.** Компилятор ZIP→ZIPB, применённый к одному и тому же исходному тексту,
даёт байт-в-байт идентичный .zipb (детерминизм). При самосборке runtime через #runtime
получается воспроизводимый компилятор_v2 (как для selfc).

**Доказательство.**

- Экспериментально: компилятор_v1(P) = компилятор_v2(P) (SHA-256 совпадает) —
  см. 	ests/тест_самокомпиляции.rs.
- Формально: следует из детерминизма фронтенда (лексер/парсер/IR/эмиттер без энтропии).

**QED**.
