# АРХИТЕКТУРА ZIP

Источник: [МАСТЕР-ПЛАН.md](../МАСТЕР-ПЛАН.md), части III и IV.

## ЧАСТЬ III. Архитектура

### 3.1. Пятислойная архитектура

```text
┌─────────────────────────────────────────────────────────┐
│ СЛОЙ 5: ZIP STD (стандартная библиотека)                │
│ Ядро, тензоры, нейросети, сеть, крипто, файлы           │
├─────────────────────────────────────────────────────────┤
│ СЛОЙ 4: ZIP COMPILER (самокомпилирующийся на ZIP)       │
│ Лексер → Парсер → AST → IR → Оптимизатор → Кодогенератор│
├─────────────────────────────────────────────────────────┤
│ СЛОЙ 3: ZIP VM (виртуальная машина)                     │
│ Байт-код, регистры, планировщик импульсов               │
├─────────────────────────────────────────────────────────┤
│ СЛОЙ 2: LLVM BACKEND                                    │
│ Трансляция IR в x86-64 / ARM64 / RISC-V                 │
├─────────────────────────────────────────────────────────┤
│ СЛОЙ 1: BOOTSTRAP (Rust/C bootstrap)                    │
│ Начальный компилятор для самокомпиляции                 │
└─────────────────────────────────────────────────────────┘
```

## ЧАСТЬ IV. Этапы создания (дорожная карта)

### ЭТАП 1: ФУНДАМЕНТ (Месяц 1)

**Цель:** Работающий лексер, парсер, AST.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 1.1 | Инициализация проекта, Git | ✅ |
| 1.2 | Спецификация алфавита | ✅ |
| 1.3 | Лексер ZIP (кириллица) | ✅ |
| 1.4 | AST и парсер | ✅ |
| 1.5 | Промежуточное представление | ✅ |
| 1.6 | Генератор нативного кода | ✅ |
| 1.7 | CLI компилятора | ✅ |
| 1.8 | Стандартная библиотека (ядро) | ✅ |
| 1.9 | Первая программа | ✅ |

**Результат:** Компилятор `zipc`, транслирующий `.zip` → `.s` (ассемблер x86-64).

### ЭТАП 2: ПОЛНОЦЕННЫЙ КОМПИЛЯТОР (Месяцы 2–3)

**Цель:** Полная поддержка всех конструкций языка.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 2.1 | Полный набор операторов (`>>`, `>>>`, `||`, `!`, `~`) | ✅ |
| 2.2 | Типы данных (целые, вещественные, строки, тензоры) | 🔄 |
| 2.3 | Функции и замыкания | ⏳ |
| 2.4 | Ветвления и циклы | ⏳ |
| 2.5 | Модули и импорты | ⏳ |
| 2.6 | Обобщённое программирование | ⏳ |
| 2.7 | Оптимизатор IR | ⏳ |
| 2.8 | Проверка типов | ⏳ |
| 2.9 | Интеграция с LLVM | ⏳ |

**Результат:** Компилятор, способный собрать любую программу на ZIP.

### ЭТАП 3: ВИРТУАЛЬНАЯ МАШИНА (Месяц 4)

**Цель:** Собственная VM и байт-код.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 3.1 | Формат байт-кода `.zipc` | ⏳ |
| 3.2 | Загрузчик байт-кода | ⏳ |
| 3.3 | Интерпретатор | ⏳ |
| 3.4 | JIT-компилятор | ⏳ |
| 3.5 | Планировщик импульсов | ⏳ |
| 3.6 | Сборщик мусора (для PERFECT-объектов) | ⏳ |

**Результат:** Виртуальная машина, способная исполнять байт-код ZIP.

### ЭТАП 4: СТАНДАРТНАЯ БИБЛИОТЕКА (Месяцы 5–6)

**Цель:** Полная STD-библиотека на языке ZIP.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 4.1 | Ядро (память, числа, строки) | 🔄 |
| 4.2 | Тензорные операции | ⏳ |
| 4.3 | Слои нейросетей | ⏳ |
| 4.4 | Автоматическое дифференцирование | ⏳ |
| 4.5 | Сетевые протоколы (TCP/UDP/HTTP) | ⏳ |
| 4.6 | Постквантовая криптография | ⏳ |
| 4.7 | Работа с файлами | ⏳ |
| 4.8 | Асинхронный runtime | ⏳ |

**Результат:** Полноценная STD-библиотека, достаточная для реальных приложений.

### ЭТАП 5: ИИ И НЕЙРОСЕТИ (Месяцы 7–8)

**Цель:** Встроенная поддержка ИИ на уровне языка.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 5.1 | Тензорный тип `ТЕНЗОР<размеры>` | ⏳ |
| 5.2 | Глаголы нейросетей (`САГАН`, `САПАР`, `МАЗАГ`) | ⏳ |
| 5.3 | Автоматическое дифференцирование | ⏳ |
| 5.4 | Слияние моделей (`САПАТ`) | ⏳ |
| 5.5 | Экспорт в ONNX / TensorRT | ⏳ |
| 5.6 | CUDA/wgpu бэкенд | ⏳ |
| 5.7 | ИИ-агенты и коллективный разум | ⏳ |

**Результат:** Полноценный язык для ИИ, конкурент Python + PyTorch.
