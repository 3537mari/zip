# Модуль ZIP-архивы

Чтение ZIP (метод store) и создание простых архивов.

## Сборка

```bash
zipc собрать examples/архив_демо.zip -o архив_демо
./архив_демо
```

Runtime:

```bash
clang -O2 -DZIP_ARCHIVE_MAIN zip-std/runtime/zip_archive.c -o архив_демо
```

## API (C)

| Функция | Описание |
|---------|----------|
| `zip_архив_открыть(путь)` | открыть и прочитать каталог |
| `zip_архив_количество` | число файлов |
| `zip_архив_имя` / `размер` | метаданные |
| `zip_архив_извлечь` | данные (только store / метод 0) |
| `zip_архив_создать_простой` | один файл без сжатия |
| `zip_архив_закрыть` | закрыть |

Deflate (метод 8) в MVP не распаковывается.
