# Идеи 14–15. Ничто/Нечто + Успех/Ошибка

## Основание
В мозге есть «отсутствие сигнала» (тишина) и «реакция на стресс» (ошибка).
ZIP моделирует это через размеченные объединения (tagged unions).

## Ничто / Нечто (Идея 14)

```zip
результат = Нечто(42)
если (результат — Нечто) {
    ПечатьЧисло(нечто_значение(результат))
}

пусто = Ничто
если (пусто — Ничто) {
    ПечатьСтроки("нет значения")
}
```

## Успех / Ошибка (Идея 15)

```zip
функция делить(а, б) {
    если (б == 0) {
        возврат(Ошибка("деление на ноль"))
    }
    возврат(Успех(а / б))
}

р = делить(10, 0)
если (р — Ошибка) {
    ПечатьСтроки(ошибка_текст(р))
}
```

## Протокол
Оператор `—` (длинное тире) проверяет тег объединения.
Runtime: `zip-std/runtime/union.c`, `#runtime("union")`.
VM хранит `[тег][полезная_нагрузка]` в куче.

## Применение
- Безопасный поиск без «магических» −1
- Ошибки без исключений
- Цепочки с явной проверкой тега
