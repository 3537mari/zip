# СИНТАКСИС ZIP

Источник: [МАСТЕР-ПЛАН.md](../МАСТЕР-ПЛАН.md), часть V.

## 5.1. Базовая программа

```zip
// Программа: сложение двух чисел
СПР = { А-А: САПАР, И-А: СИПРА, О-О: СПОРО }

САПАР(2, 3) >> ЧАТАВ!
```

**Читается как:** *«Считать 2 и 3, передать импульсом, зафиксировать»*

## 5.2. Нейросеть на ZIP

```zip
// Определение слоя нейросети
МЗГ = { А-А: МАЗАГ, И-А: МИЗГА, О-О: МОЗГО }
СГН = { А-А: САГАН, И-А: СИГНА, О-О: СОГНО }
СПР = { А-А: САПАР, И-А: СИПРА, О-О: СПОРО }

// Прямой проход нейросети
прямой_проход(вход, веса) {
    САГАН(вход, веса) >> САПАР >> ЧАТАВ!
}

// Обучение на лету
обучение(данные, модель) {
    ЖАВАТ~ {
        САГАН(данные) >> САПАР(модель) >> МАЗАГ!
    }
}

// Слияние двух моделей
САПАТ(модель1, модель2) >> ЧАТАВ!
```

## 5.3. Параллельный ИИ-агент

```zip
// Хор из трёх агентов
агент_ИТ~ { ВАДАТ("логи") >> САПАР >> ЧАТАВ! }
|| агент_Текст~ { ВАДАТ("тексты") >> САПАР >> ЧАТАВ! }
|| агент_Сеть~ { САТАТ("https://api.ai") >> САПАР >> ЧАТАВ! }
```

## 5.4. Постквантовая защита

```zip
// Шифрование модели
ЗАЩИТА(модель, ключ) {
    КАРАП(модель, ключ) >> ЧАТАВ!
}

// Расшифровка при запуске
ЗАЩИТА_СНЯТЬ(модель, ключ) {
    КАРАП(модель, ключ) >> САПАР!
}
```

## Операторы потока

| Оператор | Имя | Смысл |
|----------|-----|-------|
| `>>` | Импульс | Перенос владения без копирования |
| `\|\|` | Хор | Параллельное исполнение |
| `>>>` | Сеть | Импульс через интернет |
| `!` | Фиксация | Переход в неизменяемое состояние PERFECT |
| `~` | Поток | Асинхронное исполнение |

## Структуры (structs)

Структура — составной тип данных с именованными полями.

### Объявление

```zip
структура Точка {
    х: Вещественное,
    у: Вещественное,
}

структура Студент {
    имя: Строка,
    возраст: Целое,
    средний_балл: Вещественное,
}
```

### Создание

```zip
точка = Точка { х: 1.0, у: 2.0 }
студент = Студент {
    имя: "Иван",
    возраст: 20,
    средний_балл: 4.5,
}
```

### Доступ к полям

```zip
ПечатьЧисло(точка.х)
ПечатьСтроки(студент.имя)
студент.возраст = 21
```

### Вложенные

```zip
структура Линия {
    начало: Точка,
    конец: Точка,
}

линия = Линия {
    начало: Точка { х: 0.0, у: 0.0 },
    конец: Точка { х: 1.0, у: 1.0 },
}

ПечатьЧисло(линия.начало.х)
```

Опкоды ZIPB: `NEW_STRUCT` (0x93), `LOAD_FIELD` (0x94), `STORE_FIELD` (0x95),
`GET_FIELD_PTR` (0x96). Реализованы в C-bootstrap и VM v3.
