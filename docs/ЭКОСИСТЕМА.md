# Экосистема ZIP

## Компоненты

### Пакетный менеджер `зипм`

- `зипм создать пакет` — новый пакет
- `зипм собрать --выпуск` — сборка
- `зипм добавить <имя>` — зависимость
- `зипм опубликовать` — в локальный/HTTP-реестр
- `зипм установить` — зависимости

### Реестр пакетов

- Runtime: `zip-std/runtime/http_server.c` (`#runtime("http_server")`)
- Скрипт: `реестр/сервер/сервер.zip`
- API: `/индекс`, `/пакет/{имя}/{версия}`, `/поиск?q=`
- Корень: `ZIP_REGISTRY_ROOT` / `ZIPM_REGISTRY` / каталог `реестр/`

```bash
# из корня репозитория
./zipc/target/release/zipc реестр/сервер/сервер.zip -o реестр/сервер/сервер
ZIP_REGISTRY_ROOT=$PWD/реестр ./реестр/сервер/сервер.exe
```

### Веб-сайт

- Источники: `веб-сайт/`
- GitHub Pages: workflow `deploy-site.yml`
- Playground: `веб-сайт/плейграунд.html` (+ опционально WASM)

### IDE

- VSCode-расширение, `зип-lsp`, `зип-отладчик`, `зип-профиль`

## Публикация пакета

```bash
зипм создать мой_пакет
cd мой_пакет
# ... код ...
зипм собрать --выпуск
зипм опубликовать
# HTTP: ZIPM_REGISTRY=https://registry.zip-lang.org зипм опубликовать
```
