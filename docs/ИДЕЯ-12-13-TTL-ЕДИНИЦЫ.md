# Идеи 12–13. Временные значения (TTL) + Единицы измерения

## Идея 12: TTL

### Основание

В мозге краткосрочная память ограничена по времени.
В ZIP это выражается через TTL-значения.

### Синтаксис

```zip
кэш = эфемерное(12345, 5000)  // TTL 5 секунд
если (эфемерное_жив(кэш)) {
    ПечатьЧисло(эфемерное_значение(кэш))
}
эфемерное_освободить(кэш)
```

### Применение

- Кэш с авто-очисткой
- Сессии пользователей
- Временные токены
- Буферы для потоковой обработки

### Runtime

`zip-std/runtime/ttl.c` — `#runtime("ttl")`  
VM: `zip_создать_ttl` / `zip_ttl_жив` / `zip_ttl_получить` / `zip_ttl_освободить`

## Идея 13: Единицы измерения

### Основание

В физике единицы критически важны. В ZIP тип Ю-А
обеспечивает типобезопасность измерений.

### Синтаксис

```zip
ЕД_МС = 1
ЕД_М = 2
время = измерить(100, ЕД_МС)
путь = измерить(1500, ЕД_М)

если (совместимо(время, путь)) {
    // не выполнится — разные единицы
}
сумма = измерить_сложить(время, измерить(50, ЕД_МС))
измерить_печать(сумма)
```

### Встроенные единицы

| Константа | Код | Смысл |
|-----------|-----|--------|
| ЕД_БЕЗ | 0 | безразмерная |
| ЕД_МС | 1 | миллисекунды |
| ЕД_М | 2 | метры |
| ЕД_КГ | 3 | килограммы |
| ЕД_БАЙТ | 4 | байты |
| ЕД_ГЦ | 5 | герцы |
| ЕД_ГРАДУС | 6 | градусы |
| ЕД_ПРОЦЕНТ | 7 | проценты |

### Применение

- Физические вычисления
- Аудио/видео (частоты, длительности)
- Сети (байты, мс)
- Финансы (проценты)

### Runtime

`zip-std/runtime/units.c` — `#runtime("units")`  
Демо: `examples/ttl_демо.zip`, `examples/единицы_демо.zip`
