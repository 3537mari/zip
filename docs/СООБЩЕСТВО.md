## Как присоединиться

1. Прочитайте [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)
2. Выберите платформу
3. Представьтесь в `#приветствие` (Discord)

## Роли в сообществе

### Главный мейнтейнер

- Финальное слово по архитектуре
- Мерж PR в master
- Релизы

### Мейнтейнеры

- Review PR
- Обсуждение архитектуры
- Помощь контрибьюторам

### Контрибьюторы

- Написание кода
- Документация
- Тесты
- Примеры

### Сообщество

- Issues
- Discussions
- Помощь другим

## Стать контрибьютором

См. [CONTRIBUTING.md](../CONTRIBUTING.md).

## Процесс RFC

Для крупных изменений:

1. Создайте RFC в `rfcs/` по шаблону
2. Публичное обсуждение 2 недели
3. Голосование мейнтейнеров
4. Реализация (если одобрено)

## Еженедельные встречи

- **Когда:** Каждую пятницу, 18:00 МСК
- **Где:** Discord, канал `#встреча`
- **Темы:** обсуждение PR, идеи, помощь
