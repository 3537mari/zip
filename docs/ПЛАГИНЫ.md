# Плагины ZIP для редакторов

## VSCode / Cursor

См. [`vscode-zip/`](../vscode-zip/).

## Neovim

См. [`nvim-zip/`](../nvim-zip/).

Установка (lazy.nvim): `require("zip").setup({})`.

## Emacs

См. [`emacs-zip/`](../emacs-zip/).

Установка: `(require 'zip-mode)` и `zip-lsp-setup`.

## Общие компоненты

| Компонент | Путь / команда |
|-----------|----------------|
| LSP-сервер | `зип-lsp` |
| Компилятор | `zipc` |
| Профилировщик | `зип-профиль` |
| Отладчик | `зип-отладчик` |
| TextMate-грамматика | `vscode-zip` |

## Проверка

Откройте [`examples/плагин_тест.zip`](../examples/плагин_тест.zip):

- Neovim: `filetype` = `zip`, подсветка ключевых слов
- Emacs: major mode `zip-mode`
- LSP: диагностика / автодополнение через `зип-lsp`
