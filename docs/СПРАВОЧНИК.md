## Лексика

### Алфавит

Идентификаторы и ключевые слова — **кириллица** (33 буквы) плюс цифры, `_` и операторы.

### Идентификаторы

- Начинаются с кириллической буквы
- Далее: кириллица, цифры, `_`
- Примеры: `счётчик`, `данные_1`, `результат`

Латинские буквы в идентификаторах **запрещены** (ошибка лексики).

### Ключевые слова

| Слово | Значение |
|-------|----------|
| `если` | условный оператор |
| `иначе` | альтернативная ветка |
| `пока` | цикл с предусловием |
| `для` | цикл по диапазону / коллекции |
| `в` | оператор вхождения (`для и в 0..n`) |
| `возврат` | возврат из функции |
| `прервать` | выход из цикла |
| `продолжить` | следующая итерация |
| `функция` | объявление функции |
| `тип` | объявление типа |
| `глагол` | специализация / overload |
| `агент` | агент с состоянием |
| `поток` | поток данных |
| `Нечто` | опциональное значение |
| `Ничто` | отсутствие значения |
| `Успех` | успешный результат |
| `Ошибка` | ошибка |
| `истина` / `ложь` | булевы литералы |
| `и` / `или` / `не` | логика |

### Операторы

| Оператор | Значение |
|----------|----------|
| `>>` | импульс (передача владения) |
| `>>>` | сетевой импульс |
| `\|\|` | параллельный хор |
| `!` | фиксация PERFECT |
| `~` | асинхронный поток / async-функция |
| `=` | присваивание |
| `==` `!=` | равенство / неравенство |
| `>` `<` `>=` `<=` | сравнения |
| `+` `-` `*` `/` | арифметика |
| `..` | диапазон |
| `—` | проверка тега / типа (`результат — Нечто`) |

### Комментарии

```zip
// Однострочный комментарий

/* Многострочный
   комментарий */
```

### Директивы

Строки вида `#имя(...)` обрабатываются лексикой/парсером:

```zip
#link("libc")
#runtime("http_client")
#зависимость("нейросети = 1.0")
```

## Типы данных

### Примитивные

| Тип | Описание |
|-----|----------|
| Целое / `Целое64` | 64-битное знаковое |
| Вещественное / `Вещественное64` | 64-битное float |
| Флаг | булево (0/1) |
| Строка | UTF-8 |

### Составные (шаблоны гласных)

| Шаблон | Тип | Пример |
|--------|-----|--------|
| И-А | Множество / буфер | `СИПРА` |
| Ы-А | Итератор | `СЫПРА` |
| СТК / структура | Именованные поля | поля агента |

### Специальные

| Тип | Описание |
|-----|----------|
| `Нечто<T>` | опциональное значение |
| `Ничто` | отсутствие значения |
| `Успех<T>` | успешный результат |
| `Ошибка<E>` | ошибка |
| `Эфемерное<T>` | значение с TTL |
| `Единица<T, "мс">` | величина с единицей |

## Выражения

### Арифметика

```zip
а + б
а - б
а * б
а / б
-а
```

### Логика

```zip
а и б
а или б
не а
```

### Сравнения

```zip
а == б
а != б
а > б
а < б
а >= б
а <= б
```

### Проверка типа / тега

```zip
результат — Нечто
результат — Успех
```

### Диапазон

```zip
0..100
от..до
```

### Импульс и хор

```zip
источник >> приёмник!
ЖАВАТ~ { работа() } || ЖАВАТ~ { другая() }
```

Приоритет (низкий → высокий): `||` → `>>`/`>>>` → `~` → `!` → сравнения → `+`/`-` → `*`/`/` → унарный `-` → вызов.

## Инструкции

### Присваивание

```zip
имя = выражение
```

### Условие

```zip
если (условие) {
    // …
} иначе если (другое) {
    // …
} иначе {
    // …
}
```

### Циклы

```zip
для и в 0..10 {
    печать_число(и)
}

для элемент в СЫПРА_из_СИПРА(массив) {
    печать_число(элемент)
}

пока (условие) {
    // …
}
```

### Возврат и управление циклом

```zip
возврат
возврат(значение)
прервать
продолжить
```

## Функции

### Объявление

```zip
функция имя(параметр1, параметр2) {
    возврат(результат)
}
```

### С типами

```zip
функция сложить(а: Целое, б: Целое) -> Целое {
    возврат(а + б)
}
```

### Асинхронная

```zip
функция скачать(url) ~ {
    данные = получить(url)
    возврат(данные)
}
```

### Специализация (`глагол`)

```zip
глагол САПАР(а: Целое, б: Целое) -> Целое {
    возврат(а + б)
}

глагол САПАР(а: Тензор, б: Тензор) -> Тензор {
    возврат(матричное_умножение(а, б))
}
```

Точка входа по умолчанию — `главная` (или `main` в байт-коде VM).

## Аннотации

Синтаксис: `@имя` или `@имя(параметр = значение)` перед `функция`.

| Аннотация | Назначение |
|-----------|------------|
| `@пластичность(порог)` | порог «горячести» для JIT |
| `@comptime` | свернуть на этапе компиляции |
| `@ускорить(уровень)` | уровень оптимизации |
| `@кэшировать(размер)` | кэш результатов |
| `@шифровать(алгоритм)` | шифрование |
| `@параллелить(потоков)` | параллелизм |
| `@сон(интервал)` | авто-прунинг |
| `@тест(случай, диапазон, границы)` | автотесты |
| `@нейрогенез(порог, паттерн)` | композиты IR |
| `@проверить_шаблон(шаблон)` | проверка шаблона типа |

## Корни и шаблоны

- 3 буквы (обычно согласные) — семантическое ядро
- 64 корня в категориях (см. модуль `корни` / docs)
- 10 шаблонов гласных задают роль формы

| Шаблон | Тип | Пример |
|--------|-----|--------|
| А-А | Глагол | САПАР |
| Е-А | Свойство | СЕПАР |
| Ё-А | Особая форма | СЁПАР |
| И-А | Множество | СИПРА |
| О-О | Инструмент | СПОРО |
| У-А | Указатель | СУПРА |
| Ы-А | Итератор | СЫПРА |
| Э-А | Эфемерное | СЭПРА |
| Ю-А | Единица | СЮПРА |
| Я-А | Ядро | СЯПРА |

### Комплементарность

Обратный корень (реверс согласных) и обратный глагол создаются автоматически:

| Прямой | Обратный |
|--------|----------|
| СПР / САПАР | РПС / РАПАС |
| ЧТВ | ВТЧ |
| ЖВТ | ТВЖ |

## Специальные конструкции

### Агент

```zip
агент ИмяАгента {
    состояние {
        поле1: Тип = значение
    }

    функция метод(аргументы) {
        // доступ к полям состояния
    }
}
```

### Поток данных

```zip
поток ИмяПотока {
    источник = …
    фильтр имя = …
    приёмник = …
}
```

### Директивы

```zip
#link("libc")                 // C-библиотека / FFI
#runtime("http_server")       // встроенный C-runtime
#зависимость("имя = 1.0")     // пакет для зипм / cargo-script
```

Shebang для скриптов (R7):

```zip
#!/usr/bin/env -S zipc запустить --llvm
```
