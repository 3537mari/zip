# Оптимизация компилятора ZIP

## Что оптимизировано

### 1. Лексика
- Предварительное резервирование вектора токенов
- Классификация слов без промежуточного `Vec<char>` (один проход `chars()`)
- `match` по ключевым словам + инлайн-проверки кириллицы

### 2. Парсер
- `Parser::это` / `вперёд` без клонирования `Токен` на каждый look-ahead
- `Vec::with_capacity` для списка объявлений
- `Парсер::из_токенов` / `из_токенов_с_пулом` — без повторной лексики в `zipc`

### 3. IR
- `std::mem::take` вместо `clone()` всего списка функций
- Разбор через `разобрать_исходник_с_пулом` (bump-пул)
- Индекс функций по имени (`HashMap`) — уже был

### 4. Байт-код v3
- `HashMap` для таблицы строк (было O(n) `position`)
- `HashMap` id→индекс функции (было линейное `position` на каждый `Call`)
- Предварительное резервирование буферов `ops` / `код`

## Результаты (criterion, estimate)

| Этап | До | После | Ускорение |
|------|-----|-------|-----------|
| Лексика (1000) | 1.34 ms | 0.91 ms | 1.47× |
| Парсер (1000) | 4.11 ms | 2.72 ms | 1.51× |
| IR (1000) | 5.81 ms | 4.16 ms | 1.40× |
| Байт-код (1000) | 4.55 ms | 0.49 ms | 9.20× |
| **Пайплайн (1000)** | **15.81 ms** | **8.28 ms** | **1.91×** |
| **Пайплайн (5000)** | **166.0 ms** | **55.9 ms** | **2.97×** |

**Общее ускорение пайплайна: ~1.9–3.0×** (цель 2× достигнута на ≥1000 функциях).

Сырые логи: `zipc/базовый_результат.txt`, `zipc/оптимизированный_результат.txt`.
