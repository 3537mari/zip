# Виртуальная машина ZIP v3

Полноценный интерпретатор байт-кода `.zipb` **без LLVM**.

## Архитектура

```
┌─────────────────────────────┐
│ МодульV3 (.zipb / ZIPB)     │
│ - функции (код байтами)     │
│ - строки                    │
└─────────────────────────────┘
             ↓ декод ИнстрV3
┌─────────────────────────────┐
│ ИсполнительV3               │
│ - стек значений             │
│ - кадры вызовов / регистры  │
│ - PULSE / PERFECT_LOCK/CHOR │
│ - встроенные функции        │
└─────────────────────────────┘
```

## Отличия от VM v2

| Характеристика | VM v2 | VM v3 |
|----------------|-------|-------|
| Байт-код | `.zipc` | `.zipb` |
| Магия | `ZIPC` | `ZIPB` |
| Опкодов | ~30 | 50+ |
| Типы | i64/f64 | + Нечто/Успех/Множество/Совершенное |
| Встроенные | C runtime | внутри VM |
| LLVM | для `.exe` | не нужен |

## Использование

```bash
# Компилировать в байт-код v3
zipc программа.zip --байткод-v3 -o программа

# Запустить через VM v3
zip-vm программа.zipb
zip-vm программа.zipb --v3   # явно
zip-vm программа.zipb --дамп
```

## Встроенные функции

- `печать_число` / `ПечатьЧисло`, `печать_строки` / `ПечатьСтроки`, `печать`
- `длина_строки`, `соединить_строки`
- `модуль`, `минимум`, `максимум`
- `сипра_создать`, `сипра_добавить`, `сипра_длина`

Опкоды `PRINT` / `PRINT_LN` / `PRINT_I64` обрабатываются напрямую.
