# Идея 3. Нейрогенез — генерация функций через ИИ

## Основание

Мозг создаёт новые нейроны для обработки повторяющихся сигналов.
ZIP замечает паттерны в IR и генерирует композитные глаголы.

## Синтаксис

```zip
@нейрогенез(порог = 5, паттерн = "САПАР")
функция главная() {
    для и в 0..100 {
        данные = САПАР(и)
        результат = САПАР(данные)
    }
}
```

Параметры:

| Параметр | Значение по умолчанию | Смысл |
|----------|----------------------|--------|
| `порог` | 2 | минимальная частота окна в IR |
| `паттерн` | (нет) | фильтр по имени глагола в сигнатуре |

## Как работает

1. Компилятор анализирует IR всех функций
2. Ищет повторяющиеся последовательности (паттерны) интересных инструкций
3. Для часто встречающихся — генерирует композитную функцию `КОМПОЗИТ_…`
4. Композитная функция = один вызов вместо цепочки

## Преимущества

- Меньше кода — одна функция вместо цепочки
- Быстрее — оптимизатор лучше работает с композитом
- Автоматически — не нужно писать вручную

## Применение

- Оптимизация горячих путей
- Автогенерация обёрток
- Адаптация под железо
