# Идеи 16–17. Потоково-ориентированное + Агентно-ориентированное программирование

## Идея 16: Потоковое программирование

### Основание

Мозг обрабатывает информацию как поток. В ZIP — явная конструкция `поток`.

### Синтаксис

```zip
поток обработка_видео {
    источник = ВАДАТ(камера)
    фильтр размытие = САПАР(фильтр_размытия)
    фильтр края = САПАР(детектор_краёв)
    приёмник = ЧАТАВ(результат)
}
```

Цепочка разворачивается в импульсный конвейер: `источник >> фильтр1 >> … >> приёмник`.
Именованный поток запускается через `запустить_поток(имя)`.

### Применение

- Обработка видео/аудио
- Потоковая аналитика
- Big Data / IoT

## Идея 17: Агентное программирование

### Основание

Каждый глагол в мозге — маленький агент с состоянием.

### Синтаксис

```zip
агент СканерЛогов {
    состояние {
        последняя_позиция: Целое = 0
    }

    функция слушать() { ... }

    функция реагировать(событие) { ... }
}
```

Поля состояния — глобальные слоты; методы — функции `Агент_метод`.
Конструктор: `создать_Агент()`. Доступ: `агент.поле`, `агент.метод()`.

### Применение

- Автономные ИИ-агенты
- Мониторинг систем
- Умные дома / торговые боты

## Runtime

- `#runtime("stream")` → `zip-std/runtime/stream.c`
- `#runtime("agent")` → `zip-std/runtime/agent.c`
