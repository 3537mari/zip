# Компилятор ZIP на ZIP

## Полная независимость

С v2.0.0 цепочка компиляции в байт-код ZIPB написана **в zip-self** (без LLVM):

| Этап | Файл (спека) | Runtime |
|------|--------------|---------|
| Лексер | `zip-self/лексика.zip` | `лексика_rt.c` |
| Парсер | `zip-self/парсер.zip` | `парсер_rt.c` |
| IR | `zip-self/промежуток.zip` | `промежуток_rt.c` |
| Эмиттер v3 | `zip-self/байткод_эмиттер.zip` | `байткод_эмиттер_rt.c` / `bytecode_emitter_rt.c` |
| Компилятор | `zip-self/компилятор.zip` | `компилятор_rt.c` / `compiler_rt.c` |

## Единственная зависимость

Внешний bootstrap — C-runtime для:

- аллокации и файлового I/O;
- аргументов командной строки;
- первой сборки через `clang` / `zipc` (`#runtime`).

**Этот runtime можно постепенно переписать на ZIP** (v2.1.0).

## Цепочка компиляции

```
программа.zip
    ↓  лексер на ZIP
токены
    ↓  парсер на ZIP
AST
    ↓  IR-генератор на ZIP
промежуточное представление
    ↓  кодогенератор v3 на ZIP
программа.zipb
    ↓  zip-vm (без LLVM)
результат
```

## Использование

```bash
# Bootstrap (первая сборка через zipc / clang)
zipc zip-self/компилятор.zip -o zip-self/компилятор_v1

# Компиляция программы в ZIPB
./zip-self/компилятор_v1 examples/привет_мир.zip привет.zipb

# Запуск на VM v3
zip-vm привет.zipb
```

## Самокомпиляция

```bash
# Компилятор v1 собирает себя (как selfc: #runtime → clang)
./zip-self/компилятор_v1 zip-self/компилятор.zip zip-self/компилятор_v2.zipb
# → zip-self/компилятор_v2.exe (+ маркер .zipb)

# Фиксированная точка: одинаковый ZIPB для одной программы
./zip-self/компилятор_v1 examples/байткод_v3_полное_демо.zip a.zipb
./zip-self/компилятор_v2 examples/байткод_v3_полное_демо.zip b.zipb
# a.zipb == b.zipb
```

## Отличие от LLVM-selfc

| | `нативный.zip` / selfc | `компилятор.zip` |
|--|------------------------|------------------|
| Цель | `.exe` через LLVM/clang | `.zipb` для VM v3 |
| Нужен LLVM | да (для программ) | нет |
| Runtime | `нативный_rt.c` | `compiler_rt.c` |
