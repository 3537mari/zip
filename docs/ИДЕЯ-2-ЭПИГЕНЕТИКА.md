# Идея 2. Эпигенетика — аннотации `@`

## Основание
Эпигенетика меняет экспрессию генов без изменения ДНК.
В ZIP аннотации `@...` управляют компилятором и VM, не меняя логику программы.

## Встроенные аннотации

| Аннотация | Параметры | Эффект |
|-----------|-----------|--------|
| `@пластичность` | `порог` | Горячие пути (Идея 4) |
| `@comptime` | — | Свёртка на этапе компиляции (R2) |
| `@ускорить` | `уровень` (0–3) | Агрессивная оптимизация |
| `@кэшировать` | `размер` | Метаданные кэша (+ `runtime/cache.c`) |
| `@шифровать` | `алгоритм` | LLVM `optnone`, метка крипто |
| `@параллелить` | `потоков` | Метаданные пула (+ `runtime/parallel.c`) |
| `@сон` | `интервал` | Авто-прунинг (метка) |
| `@тест` | `случай` | Автогенерация `*_тесты.zip` |

## Пример
```zip
@ускорить(уровень = 3)
@кэшировать(размер = 1024)
функция дорогая(х) {
    возврат(х * х)
}
```

Неизвестная аннотация — ошибка компиляции.
