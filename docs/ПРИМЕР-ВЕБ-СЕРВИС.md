# Пример: TODO-сервис на ZIP

Production-ready REST API для управления задачами.

Исходники: [`examples/todo_сервис/`](../examples/todo_сервис/).

## Архитектура

```
┌─────────────────────────────────────────┐
│ HTTP-клиент (curl, браузер, PowerShell) │
└────────────────┬────────────────────────┘
                 │ HTTP
                 ↓
┌─────────────────────────────────────────┐
│ HTTP-сервер (ZIP #runtime("todo_api"))  │
│  - маршрутизация                        │
│  - аутентификация Bearer                │
│  - логирование                          │
└────────────────┬────────────────────────┘
                 │
                 ↓
┌─────────────────────────────────────────┐
│ Агент TodoAPI (состояние)               │
│  - задачи, токены, следующий_id         │
│  - CRUD + вход                          │
└────────────────┬────────────────────────┘
                 │
                 ↓
┌─────────────────────────────────────────┐
│ JSON-хранилище (файл)                   │
│  - данные/задачи.json                   │
└─────────────────────────────────────────┘
```

## Модули ZIP

| Файл | Роль |
|------|------|
| `src/главная.zip` | Точка входа (`#runtime("todo_api")`) |
| `src/роутер.zip` | Контракт маршрутов |
| `src/модели.zip` | Контракт `Задача` |
| `src/хранилище.zip` | Контракт JSON DB (+ unit-тест) |
| `src/аутентификация.zip` | Контракт токенов |

Реализация HTTP/JSON/файлов: `zip-std/runtime/todo_api.c` (как GEMM/XOR/реестр — STD runtime, собираемый zipc).

## Что использовано

| Модуль | Откуда |
|--------|--------|
| HTTP-сервер | `#runtime("todo_api")` / Winsock |
| JSON DB | файл `данные/задачи.json` |
| Токены | Bearer + хеш-токен |
| ZIP-модули | контракт и документация API |
| Тесты | `тестировать.ps1`, `todo_api_test` |

## API

| Метод | Путь | Auth | Описание |
|-------|------|------|----------|
| GET | `/health` | нет | статус |
| POST | `/api/вход` или `/api/login` | нет | `{"имя","пароль"}` → токен |
| GET | `/api/задачи` или `/api/tasks` | Bearer | список |
| POST | `/api/задачи` или `/api/tasks` | Bearer | создать |
| GET | `/api/задачи/{id}` или `/api/tasks/{id}` | Bearer | получить |
| PUT | `/api/задачи/{id}` или `/api/tasks/{id}` | Bearer | обновить |
| DELETE | `/api/задачи/{id}` или `/api/tasks/{id}` | Bearer | удалить |

Кириллические пути поддерживаются (с URL-decode); ASCII-алиасы удобны для curl/PowerShell.

Демо-учётка: `admin` / `admin`.

## Запуск

```powershell
cd examples/todo_сервис
..\..\zipc\target\release\zipc.exe собрать src\главная.zip -o сервер
.\сервер
```

Тесты:

```powershell
pwsh .\тестировать.ps1
```
