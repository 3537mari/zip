# R4–R6. Три улучшения из Rust

## R4. Range Copy

Диапазоны как Copy-типы — можно использовать многократно.

```zip
д = 0..100
для и в д { ... }   // первый раз
для и в д { ... }   // второй раз — работает
```

Реализация: `Тип::Диапазон`, runtime `zip_создать_диапазон` /
`zip_копировать_диапазон` / `zip_диапазон_*`, при итерации и присваивании —
копия (не move).

## R5. assert_matches!

Проверка соответствия шаблону на входе функции.

```zip
@проверить_шаблон(шаблон = "Нечто(_)")
функция получить(опция) { ... }
```

Поддерживаемые теги: `Нечто`, `Ничто`, `Успех`, `Ошибка`.
При несоответствии вызывается `zip_паника_шаблон`.

## R6. FFI overloading

Разные варианты одной C-функции по арности.

```zip
#link("ffi_overload")
функция максимум(а: Число, б: Число) -> Число
функция максимум(а: Число, б: Число, в: Число) -> Число
```

Компилятор регистрирует `zip_максимум_2` / `zip_максимум_3` и выбирает
символ по числу аргументов. Пример runtime: `zip-std/runtime/ffi_overload.c`.
