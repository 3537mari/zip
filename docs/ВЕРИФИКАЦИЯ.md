# Формальная верификация ZIP

## Что проверяется

1. **Типовая безопасность** — операнды арифметики/сравнений совместимы, стек не опустошается некорректно
2. **Владение** — Move/PULSE: нет чтения регистра после передачи
3. **PERFECT-инвариант** — нет Store в регистр после PerfectLock
4. **Согласованность стека** — часть проверки типов (баланс push/pop)

Спецификация: [ФОРМАЛЬНАЯ-СЕМАНТИКА.md](ФОРМАЛЬНАЯ-СЕМАНТИКА.md), теоремы: [ТЕОРЕМЫ.md](ТЕОРЕМЫ.md).

## Использование

`ash
# Все проверки
cargo run --manifest-path zip-verify/Cargo.toml --release -- программа.zipb

# Только типы
cargo run --manifest-path zip-verify/Cargo.toml --release -- программа.zipb --проверка типы

# JSON-отчёт
cargo run --manifest-path zip-verify/Cargo.toml --release -- программа.zipb --json report.json
`
