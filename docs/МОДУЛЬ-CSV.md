# Модуль CSV

Парсер таблиц CSV/TSV в ZIP STD.

## Сборка

```bash
zipc собрать examples/csv_демо.zip -o csv_демо
./csv_демо
```

## Разбор

```zip
#runtime("csv_parser")
// C: zip_csv_разобрать(текст, разделитель)
```

Обёртки в `zip-std/csv.zip` (кириллица): `разобрать_цсв`, `разобрать_тсв`.

## Доступ

| C API | Описание |
|-------|----------|
| `zip_csv_получить(т, строка, колонка)` | ячейка |
| `zip_csv_строк(т)` | число строк |
| `zip_csv_колонок(т, строка)` | колонок в строке |
| `zip_csv_записать(т, sep)` | сериализация |

## Возможности

- разделитель `,` или `\t`
- кавычки `"..."` и экранирование `""`
- `\r\n` / `\n`
