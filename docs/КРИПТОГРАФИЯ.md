# Криптография в ZIP

## Что реализовано

| Алгоритм | Статус | Реализация |
|----------|--------|------------|
| **SHA-256** | ✅ | Чистый ZIP / `zip-crypto` + STD |
| **SHA-3-256** | ✅ | `zip-crypto` |
| **AES-256-GCM** | ✅ | **Чистый ZIP** (`zip-std/крипто_aes_zip.zip`) |
| **Kyber-1024 / ML-KEM-1024** | ⚠️ | `zip-crypto` (`ml-kem`, FIPS 203) — перенос v7.4.1 |
| **Dilithium-5 / ML-DSA-87** | ⚠️ | `zip-crypto` (`fips204`, FIPS 204) — перенос v7.4.2 |
| **Constant-time сравнение** | ✅ | Чистый ZIP + `subtle` |
| **getrandom** | ✅ | OS CSPRNG (`getrandom` / BCrypt / getentropy) |

**Никакого OpenSSL в основном пути.**

## AES-256-GCM (v7.4.0)

**Перенесён на чистый ZIP.** Больше не использует RustCrypto в VM.

| Слой | Где живёт | Что делает |
|---|---|---|
| **AES-256** | `zip-std/крипто_aes_zip.zip` | S-box, key expansion, шифрование блоков |
| **GCM** | `zip-std/крипто_aes_zip.zip` | CTR + GHASH |
| **Constant-time** | `zip-std/крипто_aes_zip.zip` | Защита от timing-атак |
| **CSPRNG** | `zip-std/runtime/syscall.c` | `getrandom` / `BCryptGenRandom` / `getentropy` |

**NIST-вектора совпадают.** Fixed-point сохранён.

### Использование

```zip
#runtime("io")
// + содержимое крипто_aes_zip.zip

функция главная() {
    ключ = [0; 32]
    iv = [0; 12]
    данные = [0; 16]
    шифротекст = [0; 16]
    тег = [0; 16]
    aes256_gcm_шифровать_с_iv(данные, 16, ключ, iv, шифротекст, тег)
    возврат(0)
}
```

## Аннотация `@шифровать`

```zip
@шифровать(алгоритм = "AES-256-GCM")
функция обработать_пароль(пароль) {
    напечатать_строку("Пароль получен")
    возврат(пароль)
}
```

- Помечает функцию как крипто-чувствительную (`optnone` в LLVM).
- Реализация шифрования — **чистый ZIP** (`aes256_gcm_шифровать`).
- Алгоритм по умолчанию: **AES-256-GCM**.

## Что осталось на RustCrypto

| Алгоритм | Статус |
|---|---|
| AES-256-GCM | ✅ **Чистый ZIP** (v7.4.0) |
| SHA-256 / SHA-3 | ✅ Чистый ZIP / zip-crypto |
| **Kyber-1024** | ⚠️ RustCrypto (v7.3.0) — перенос в v7.4.1 |
| **Dilithium-5** | ⚠️ RustCrypto (v7.3.0) — перенос в v7.4.2 |

## Постквантовая защита

- **ML-KEM-1024** (бывш. Kyber-1024): pk 1568, sk 3168, ct 1568, ss 32.
- **ML-DSA-87** (бывш. Dilithium-5): pk 2592, sk 4896, sig **4627** (FIPS 204).
