# Криптография в ZIP

## Что реализовано

| Алгоритм | Статус | Реализация |
|----------|--------|------------|
| **SHA-256** | ✅ | `zip-crypto` + ZIP STD (`крипто_zip.zip`) |
| **SHA-3-256** | ✅ | `zip-crypto` |
| **AES-256-GCM** | ✅ | `zip-crypto` (`aes-gcm`, без OpenSSL) |
| **Kyber-1024 / ML-KEM-1024** | ✅ | `zip-crypto` (`ml-kem`, FIPS 203) |
| **Dilithium-5 / ML-DSA-87** | ✅ | `zip-crypto` (`fips204`, FIPS 204) |
| **Constant-time сравнение** | ✅ | `subtle` / `constant_time_eq` |
| **getrandom** | ✅ | OS CSPRNG (`getrandom` / BCrypt / getentropy) |

**Никакого OpenSSL в основном пути.** Legacy `#runtime("crypto")` больше не линкует OpenSSL:
CSPRNG + SHA-256 в C; AES/PQ — только через VM / `zip-crypto`.

## Использование (ZIP / VM builtins)

```zip
функция главная() {
    ключ = случайные_байты(32)
    пакет = шифровать_аес("секрет", ключ)
    текст = расшифровать_аес(пакет, ключ)
    возврат(0)
}
```

| ZIP API | Builtin |
|---------|---------|
| `хеш_ша256` | `zip_std_sha256` |
| `случайные_байты` | `zip_crypto_random` |
| `шифровать_аес` / `расшифровать_аес` | `zip_crypto_aes_*` |
| `kyber1024_*` | `zip_crypto_kyber_*` |
| `dilithium5_*` | `zip_crypto_dilithium_*` |
| `constant_time_eq` | `zip_crypto_ct_eq` |

Формат AES-пакета: `iv_hex:tag_hex:ciphertext_hex`.

## Аннотация `@шифровать`

```zip
@шифровать(алгоритм = "AES-256-GCM")
функция обработать_пароль(пароль) {
    напечатать_строку("Пароль получен")
    возврат(пароль)
}
```

- Помечает функцию как крипто-чувствительную (`optnone` в LLVM).
- В IR объявляются `zip_crypto_aes_encrypt` / `decrypt` / `random`.
- Алгоритм по умолчанию: **AES-256-GCM**.

## Постквантовая защита

- **ML-KEM-1024** (бывш. Kyber-1024): pk 1568, sk 3168, ct 1568, ss 32.
- **ML-DSA-87** (бывш. Dilithium-5): pk 2592, sk 4896, sig **4627** (FIPS 204).
- Основа: MLWE / MSIS — устойчивость к алгоритму Шора.
