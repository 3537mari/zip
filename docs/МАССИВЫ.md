# Массивы в ZIP

## Типы массивов

### Фиксированный размер

```zip
числа: [Целое; 10]
```

## Литералы

```zip
числа = [1, 2, 3, 4, 5]
нули = [0; 10]
матрица = [[1, 2], [3, 4]]
```

## Доступ

```zip
значение = числа[0]
числа[0] = 10
длина = длина_массива(числа)
```

## Итерация

```zip
для и в 0..длина_массива(числа) {
    ПечатьЧисло(числа[и])
}
```

## Опкоды ZIPB

| Опкод | Код | Назначение |
|-------|-----|------------|
| `NEW_ARRAY` | 0x97 | Создать массив |
| `LOAD_INDEX` | 0x98 | Загрузить по индексу |
| `STORE_INDEX` | 0x99 | Записать по индексу |
| `ARRAY_LEN` | 0x9A | Длина массива |

## Пример: среднее значение

```zip
функция среднее(числа) {
    сумма = 0
    для и в 0..длина_массива(числа) {
        сумма = сумма + числа[и]
    }
    возврат(сумма / длина_массива(числа))
}

функция главная() {
    данные = [1, 2, 3, 4, 5]
    ПечатьЧисло(среднее(данные))   // 3
}
```

## Пример: матричное умножение

```zip
функция умножить_матрицы(а, б, н) {
    результат = [[0; н]; н]
    для и в 0..н {
        для j в 0..н {
            сумма = 0
            для k в 0..н {
                сумма = сумма + а[и][k] * б[k][j]
            }
            результат[и][j] = сумма
        }
    }
    возврат(результат)
}
```
