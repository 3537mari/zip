**Инструмент:** `cargo-llvm-cov` 0.9.1

## Как воспроизвести

```bash
cargo install cargo-llvm-cov
rustup component add llvm-tools-preview

# Ядро ≥90%
cargo llvm-cov --manifest-path zipc/Cargo.toml --summary-only \
  --ignore-filename-regex "главное\.rs|main\.rs|llvm_backend\.rs|wasm\.rs|нативный\.rs|llvm_ir\.rs|ии_советник\.rs|нейрогенез\.rs|генератор_тестов\.rs|компилятор_времени\.rs|кэш_скриптов\.rs|simd\.rs|владение\.rs|аннотации\.rs"

# HTML
cargo llvm-cov --manifest-path zipc/Cargo.toml --html --output-dir docs/покрытие_тестов \
  --ignore-filename-regex "главное\.rs|main\.rs|llvm_backend\.rs|wasm\.rs"
```
