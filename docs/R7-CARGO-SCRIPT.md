# R7. Расширения cargo-script

## Shebang

ZIP-скрипты можно запускать как обычные executable.

```bash
chmod +x скрипт.zip
./скрипт.zip
```

Или явно:

```bash
zipc запустить скрипт.zip --llvm
```

## Inline-зависимости

```zip
#зависимость("тензоры = 1.0")
#зависимость("нейросети = 0.5")
```

При запуске проверяется каталог `зипм_пакеты/` и предлагается `зипм добавить`.

## Кэш скриптов

Ключ кэша — SHA-256 содержимого исходника. Повторный запуск без перекомпиляции:

```bash
zipc запустить программа.zip
# ✓ Использую кэш: ...
```

## Управление кэшем

```bash
zipc кэш статистика
zipc кэш очистить
```

## Преимущества

- Быстро — повторные запуски без перекомпиляции
- Удобно — как Python / cargo-script
- Автономно — не нужен манифест
- Inline-зависимости вместо TOML
