# Алфавит ZIP

## Согласные (строительные блоки корней)
Б, В, Г, Д, Ж, З, Й, К, Л, М, Н, П, Р, С, Т, Ф, Х, Ц, Ч, Ш, Щ

## Гласные (шаблоны/модификаторы)
А, Е, Ё, И, О, У, Ы, Э, Ю, Я

## Специальные символы
>> — импульс вперёд
|| — параллельный хор
>>> — сетевой импульс
! — фиксация PERFECT
~ — асинхронный поток IMPERFECT
= — объявление
: — разделитель шаблонов
( ) { } , — стандартные разделители
" — строки
// — комментарии
# — директива компилятора
