# R2. comptime — метапрограммирование на этапе компиляции

## Основание

В Rust — Project Goal: Reflection and comptime. В ZIP — аннотация
`@comptime` и интерпретация IR на этапе компиляции.

## Синтаксис

```zip
@comptime
функция факториал(н) {
    если (н < 2) { возврат(1) }
    иначе { возврат(н * факториал(н - 1)) }
}

функция главная() {
    // На этапе компиляции: факториал(10) = 3628800
    // В .exe / .ll: только константа
    ПечатьЧисло(факториал(10))
}
```

`comptime` — единственное латинское ключевое слово (исключение в лексере).
Кириллический алиас аннотации: `@комптайм`.

## Как работает

1. `@comptime` помечает `ФункцияПП.comptime = true`.
2. После генерации IR компилятор находит вызовы с константными аргументами.
3. `КомпиляторВремени` интерпретирует тело (арифметика, сравнения, ветвления, рекурсия).
4. Вызов заменяется на `КонстантаЦелое`.
5. Неиспользуемые comptime-функции удаляются из модуля (в `.ll` нет рекурсии).

Лимит шагов: 1 000 000 (защита от `пока (1)`).

## Применение

- Таблицы (sin/cos, простые числа)
- Константы (факториалы, Фибоначчи)
- Проверка инвариантов на этапе компиляции
- Метапрограммирование без макросов
