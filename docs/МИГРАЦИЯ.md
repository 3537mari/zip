## Python → ZIP

### Синтаксис

| Python | ZIP |
|--------|-----|
| `def foo(x):` | `функция foo(х) {` |
| `return x` | `возврат(х)` |
| `if x > 0:` | `если (х > 0) {` |
| `else:` | `} иначе {` |
| `elif` | `} иначе если` |
| `for i in range(10):` | `для и в 0..10 {` |
| `while x < 10:` | `пока (х < 10) {` |
| `print(x)` | `печать_число(х)` |
| `print("text")` | `печать_строки("text")` |
| `# комментарий` | `// комментарий` |
| `True / False` | `истина / ложь` |
| `None` | `Ничто` |
| `and / or / not` | `и / или / не` |

### Пример: факториал

**Python:**

```python
def factorial(n):
    if n < 2:
        return 1
    return n * factorial(n - 1)

print(factorial(10))
```

**ZIP:**

```zip
функция факториал(н) {
    если (н < 2) { возврат(1) }
    возврат(н * факториал(н - 1))
}

печать_число(факториал(10))
```

### Пример: работа с массивами

**Python:**

```python
numbers = [1, 2, 3, 4, 5]
squared = [x * x for x in numbers]
print(sum(squared))
```

**ZIP:**

```zip
числа = СИПРА(5)
СИПРА_добавить(числа, 1)
СИПРА_добавить(числа, 2)
СИПРА_добавить(числа, 3)

сумма = 0
для число в СЫПРА_из_СИПРА(числа) {
    сумма = сумма + число * число
}
печать_число(сумма)
```

### Пример: нейросеть

**Python (PyTorch):**

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1),
)
x = torch.tensor([[0.5, 0.5]])
y = model(x)
```

**ZIP:**

```zip
#зависимость("нейросети = 1.0")

слой1 = создать_слой(2, 4)
слой2 = создать_слой(4, 1)
вход = создать_тензор(1, 2, 0, 0)
заполнить_тензор(вход, 2, 1, 0.5)
h = прямой_проход_слоя(слой1, вход)
выход = прямой_проход_слоя(слой2, h)
печать_число(выход)
```

### Преимущества ZIP

- нативный код через LLVM (существенно быстрее интерпретируемого Python);
- компактные агенты и потоки;
- встроенные примитивы ИИ в STD;
- крипто-runtime и анализ владения.

### Миграция пошагово

1. Установите ZIP
2. Переименуйте идентификаторы (латиница → кириллица)
3. `def` → `функция`, `if/else` → `если/иначе`
4. `for` / `while` → `для` / `пока`
5. `print` → `печать_число` / `печать_строки`
6. Проверьте через LSP и `--llvm`

## Rust → ZIP

### Синтаксис

| Rust | ZIP |
|------|-----|
| `fn foo(x: i64) -> i64 {` | `функция foo(х) {` |
| `let x = 5;` | `х = 5` |
| `if x > 0 {` | `если (х > 0) {` |
| `else {` | `} иначе {` |
| `for i in 0..10 {` | `для и в 0..10 {` |
| `while x < 10 {` | `пока (х < 10) {` |
| `println!("{}", x);` | `печать_число(х)` |
| `// комментарий` | `// комментарий` |
| `true / false` | `истина / ложь` |
| `Option<T>` | `Нечто<T>` / `Ничто` |
| `Result<T, E>` | `Успех<T>` / `Ошибка<E>` |
| `match x { ... }` | `если (х — Нечто) { ... }` |

### Пример: move-семантика

**Rust:**

```rust
fn main() {
    let s = String::from("hello");
    takes_ownership(s);
    // println!("{}", s); // ошибка: moved
}
```

**ZIP:**

```zip
функция главная() {
    с = "hello"
    САПАР(с) >> ЧАТАВ!
    // печать_строки(с)  // ошибка владения после >>
}
```

### Пример: match / Result

**Rust:**

```rust
match result {
    Ok(value) => println!("{}", value),
    Err(e) => eprintln!("{}", e),
}
```

**ZIP:**

```zip
если (результат — Успех) {
    печать_число(успех_значение(результат))
} иначе если (результат — Ошибка) {
    печать_строки(ошибка_текст(результат))
}
```

### Преимущества ZIP над Rust (для своей ниши)

- проще синтаксис для потоков и агентов;
- аннотации `@ускорить`, `@шифровать`, `@нейрогенез`;
- корни / шаблоны гласных;
- операторы `>>`, `||`, `~` как часть языка.

### Миграция пошагово

1. Установите ZIP
2. Кириллические идентификаторы
3. `fn` → `функция` (типы часто выводятся)
4. `Option`/`Result` → `Нечто`/`Успех`/`Ошибка`
5. Атрибуты → аннотации `@…`
6. Проверьте анализ владения (или `--без-владения` для прототипа)

## Что сохранить, что изменить

### Сохранить

- алгоритмы и логику;
- структуру тестов (адаптировать синтаксис);
- документацию идей (обновить примеры).

### Изменить

- идентификаторы — только кириллица;
- идиомы — потоковость вместо классов;
- аннотации вместо многих атрибутов/декораторов.

### Не переносить напрямую

- латиницу в идентификаторах;
- классическое ООП → агенты / корни;
- exceptions → `Успех` / `Ошибка`.

## Примеры миграции

### 1. Web-сервер

**Python (Flask):**

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return "Hello, World!"
```

**ZIP (скелет):**

```zip
#runtime("http_server")

агент ВебСервер {
    состояние {
        порт: Целое = 8080
    }
    функция обработать(запрос) {
        возврат("Hello, World!")
    }
}

функция главная() {
    сервер = создать_ВебСервер()
    // слушать порт — через runtime http_server
}
```

### 2. Конфиг / JSON

**Rust (serde):**

```rust
let config: Config = serde_json::from_str(&json)?;
```

**ZIP (ориентир на будущий/внешний модуль):**

```zip
#зависимость("json = 1.0")
конфиг = разобрать_json(json)
имя = конфиг.имя
порт = конфиг.порт
```

### 3. Асинхронная обработка

**Python (asyncio):**

```python
async def fetch(url):
    ...
results = await asyncio.gather(fetch(u1), fetch(u2))
```

**ZIP:**

```zip
функция скачать(url) ~ {
    возврат(получить_https(url))
}

функция главная() {
    скачать("http://example.com/1") ~
    || скачать("http://example.com/2") ~
}
```

## Заключение

ZIP концептуально близок к Python (простота) и Rust (владение / move):

| | Python | Rust | ZIP |
|--|--------|------|-----|
| Типизация | динамическая | статическая | вывод + шаблоны |
| Владение | GC | move/borrow | импульсы `>>` |
| ИИ | библиотеки | crates | STD-примитивы |
| Алфавит | латиница | латиница | **кириллица** |

Ориентиры по времени миграции:

- ~30 минут — маленькая программа;
- 1–2 дня — средний проект;
- 1–2 недели — крупный кодбаз.
