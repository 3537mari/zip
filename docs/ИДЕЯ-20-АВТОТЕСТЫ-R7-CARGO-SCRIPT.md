# Идея 20 + R7. Автогенерация тестов + cargo-script

## Идея 20: Автогенерация тестов

### Синтаксис

```zip
@тест(случай = 100, диапазон = "0..1000", границы = да)
функция сложить(а, б) -> Целое {
    возврат(а + б)
}
```

### Что генерируется

- `случай = N` — N случайных тестов
- `диапазон = "мин..макс"` — диапазон значений аргументов
- `границы = да` — плюс граничные случаи (0, мин, макс; отрицательные при мин < 0)

### Запуск

```bash
zipc тест программа.zip --llvm
# или
zipc program.zip --запустить-тесты --llvm
```

## R7: cargo-script

### Использование

```bash
# Обычно:
zipc собрать программа.zip -o программа --llvm
./программа

# С R7:
zipc запустить программа.zip --llvm
# → компиляция + запуск в одной команде

# С аргументами:
zipc запустить программа.zip --llvm -- arg1 arg2
```

### Алиасы

| Команда | Алиасы |
|---------|--------|
| `zipc запустить` | `run`, `r` |
| `zipc собрать` | `build`, `b` |
| `zipc тест` | `test`, `t` |
| `zipc версия` | `version` |

Старый режим `zipc файл.zip -o выход` сохранён для обратной совместимости.
