# Модуль Дата/Время

Работа с метками времени в ZIP STD.

## Сборка

```bash
zipc собрать examples/datetime_демо.zip -o datetime_демо
./datetime_демо
```

Runtime напрямую:

```bash
clang -O2 -DZIP_DATETIME_MAIN zip-std/runtime/datetime.c -o datetime_демо
```

## API (C)

| Функция | Описание |
|---------|----------|
| `zip_время_сейчас()` | Unix-время в миллисекундах |
| `zip_datetime_разобрать(мс)` | компоненты даты |
| `zip_datetime_собрать(...)` | собрать метку |
| `zip_datetime_формат(мс, fmt)` | `strftime` |
| `zip_datetime_парсить(строка, fmt)` | `%Y %m %d %H %M %S` |
| `zip_datetime_добавить` / `разница` | арифметика |
| `zip_секунда`…`zip_неделя` | интервалы |

Форматы: `"%Y-%m-%d %H:%M:%S"`, `"%d.%m.%Y"`, `"%H:%M"`.
