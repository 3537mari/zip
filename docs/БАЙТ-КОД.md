# Байт-код ZIP v3

Собственный формат байт-кода ZIP **без LLVM** (магия `ZIPB`).  
Сосуществует с `.zipc` v2 (`ZIPC`) для обратной совместимости.

## Общая структура

```
┌──────────────────────────────────┐
│ Заголовок (16 байт)              │
├──────────────────────────────────┤
│ Таблица строк                     │
├──────────────────────────────────┤
│ Таблица функций + байт-код        │
└──────────────────────────────────┘
```

## Заголовок (16 байт)

| Смещение | Размер | Описание |
|----------|--------|----------|
| 0 | 4 | Магия: `"ZIPB"` (`0x5A495042` LE как байты `Z I P B`) |
| 4 | 2 | Версия: `3` |
| 6 | 2 | Флаги |
| 8 | 4 | Количество функций |
| 12 | 4 | Смещение таблицы строк (обычно `16`) |

После строк сразу идёт таблица функций.

## Таблица строк

```
u32 string_count
повторить string_count раз:
  u32 byte_len
  utf-8 bytes
```

## Формат функции

```
+0:  имя (индекс в таблице строк, u32)
+4:  арность (u16)
+6:  размер локалов (u16)
+8:  флаги (u32) — bit0 async, bit1 perfect, bit2 comptime
+12: длина байт-кода (u32)
+16: байт-код
```

## Инструкции

### Стек (1 байт)

| Опкод | Имя | Описание |
|-------|-----|----------|
| 0x00 | NOP | Ничего |
| 0x01 | POP | Снять верхушку |
| 0x02 | DUP | Дублировать |
| 0x03 | SWAP | Поменять две верхушки |

### Константы

| Опкод | Имя | Операнды |
|-------|-----|----------|
| 0x10 | PUSH_I64 | i64 LE |
| 0x11 | PUSH_F64 | f64 LE |
| 0x12 | PUSH_STR | u32 индекс строки |
| 0x13 | PUSH_NULL | — |
| 0x14 | PUSH_TRUE | — |
| 0x15 | PUSH_FALSE | — |

### Арифметика / сравнения (1 байт)

`ADD SUB MUL DIV MOD` = `0x20…0x24`  
`EQ NE LT LE GT GE` = `0x30…0x35`

### Регистры / переходы / вызовы

| Опкод | Имя | Операнды |
|-------|-----|----------|
| 0x40 | LOAD | u32 reg |
| 0x41 | STORE | u32 reg |
| 0x50 | JUMP | u32 addr (индекс инструкции) |
| 0x51 | JUMP_IF | u32 addr |
| 0x52 | JUMP_IF_NOT | u32 addr |
| 0x60 | CALL | u32 fn_index |
| 0x61 | RET | — |
| 0x62 | CALL_NATIVE | u32 lib_str, u32 fn_str |

### Специальные ZIP

| Опкод | Имя | Операнды |
|-------|-----|----------|
| 0x70 | PULSE | u16 from, u16 to |
| 0x71 | PERFECT_LOCK | u16 reg |
| 0x72 | CHOIR_SPAWN | u32 fn |
| 0x73 | CHOIR_JOIN | — |
| 0x74 | ASYNC_CALL | u32 fn |

### Типы

`NEW_SET…CHECK_TAG` = `0x80…0x86`

### Вывод (практическое расширение)

| Опкод | Имя |
|-------|-----|
| 0x90 | PRINT |
| 0x91 | PRINT_LN |
| 0x92 | PRINT_I64 |

## Пример

`сложить(2, 3)` → печать:

```
PUSH_I64 2
STORE 0
PUSH_I64 3
STORE 1
LOAD 0
LOAD 1
ADD
STORE 2
LOAD 2
PRINT_I64
PUSH_I64 0
RET
```

## Инструменты

```bash
# IR → .zipb
zipc examples/байткод_v3_демо.zip --байткод-v3 -o байткод_v3

# Запуск
zip-vm байткод_v3.zipb

# Дамп
zip-vm байткод_v3.zipb --дамп
```

Файлы: `zip-vm/src/байткод_v3.rs`, `байткод_v3_декодер.rs`, `ir_в_байткод.rs`.
