## ЭТАП 6: САМОКОМПИЛЯЦИЯ (Месяц 9)

**Цель:** Компилятор ZIP, написанный на ZIP.

| Шаг | Задача | Статус |
|-----|--------|--------|
| 6.1 | Перенос лексера на ZIP | ⏳ |
| 6.2 | Перенос парсера на ZIP | ⏳ |
| 6.3 | Перенос IR-генератора на ZIP | ⏳ |
| 6.4 | Перенос кодогенератора на ZIP | ⏳ |
| 6.5 | Тест самокомпиляции: ZIP компилирует ZIP | ⏳ |
| 6.6 | Проверка байт-в-байт идентичности | ⏳ |
| 6.7 | Удаление Rust-бутстрэпа | ⏳ |

**Результат:** Полностью независимый язык, компилирующий сам себя.

## Контекст в архитектуре

Самокомпиляция опирается на:

1. **Слой 1 (BOOTSTRAP)** — начальный компилятор на Rust/C (`zipc/`, `bootstrap/`).
2. **Слой 4 (ZIP COMPILER)** — перенос конвейера на сам ZIP (`zip-self/`).

Планируемая структура `zip-self/`:

```text
zip-self/
├── лексика.zip           — лексер на самом ZIP
├── парсер.zip            — парсер на самом ZIP
├── кодогенератор.zip     — кодогенератор на самом ZIP
└── главное.zip           — точка входа на ZIP
```

Скрипт: `scripts/самокомпиляция.sh`.
