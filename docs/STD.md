# Справочник по стандартной библиотеке ZIP

Модули `zip-std/` и связанные runtime-привязки с примерами.

## Модули

### ЯДРО (`ядро.zip`)

Базовые функции: печать, модуль, минимум/максимум.

```zip
печать_число(42)
печать_строки("Привет")
модуль(-7)     // 7
минимум(3, 9)  // 3
максимум(3, 9) // 9
```

Точка входа тестов: `zip-std/тесты/тест_ядро.zip`.

---

### ТЕНЗОРЫ (`тензоры.zip`)

Операции над тензорами для нейросетей и линейной алгебры.

```zip
т = создать_тензор(512, 512, 0, 0)
заполнить_тензор(т, 512, 512, 1.0)
с = матричное_умножение(а, б, 512, 512, 512)
```

Ориентир производительности: GEMM 512×512 ≈ **4.2×** относительно NumPy (зависит от CPU / LLVM).

Тесты: `zip-std/тесты/тест_тензоры.zip`.

---

### НЕЙРОСЕТИ (`нейросети.zip`)

Слои, активации, прямой и обратный проход.

```zip
слой = создать_слой(2, 4)
выход = прямой_проход_слоя(слой, вход)
градиент = обратный_проход_слоя(слой, градиент_выхода, lr)
```

Примеры: `zip-std/примеры/нейросеть_xor.zip`, обучение XOR.

---

### СЕТЬ (`сеть.zip` + runtime)

HTTP/HTTPS через `#runtime("http_client")` / `#runtime("https_client")`.

```zip
#runtime("http_client")
ответ = http_get("http://example.com/")

#runtime("https_client")
ответ = получить_https("https://api.github.com/")
```

Тесты: `zip-std/тесты/тест_сеть.zip`.

---

### КРИПТО (`крипто` / `#runtime("crypto")`)

Хеширование, AES-GCM, случайные байты.

```zip
#runtime("crypto")
хеш = хеш_sha256_hex("привет", 6)
зашифрованное = шифровать_аес(данные, длина, ключ)
расшифрованное = расшифровать_аес(данные, длина, ключ, iv, тег)
байты = случайные_байты(32)
```

Исходники C: `zip-std/runtime/` (crypto).

---

### TTL (`#runtime("ttl")`)

Эфемерные значения с авто-удалением.

```zip
#runtime("ttl")
кэш = эфемерное(42, 5000)  // TTL 5 с
если (эфемерное_жив(кэш)) {
    печать_число(эфемерное_значение(кэш))
}
эфемерное_освободить(кэш)
```

---

### ЕДИНИЦЫ (`#runtime("units")`)

Величины с проверкой совместимости единиц.

```zip
#runtime("units")
время = измерить(100.0, ЕД_МС)
сумма = измерить_сложить(время, время)
измерить_печать(сумма)
```

Встроенные константы: `ЕД_МС`, `ЕД_М`, `ЕД_КГ`, `ЕД_БАЙТ`, `ЕД_ГЦ`, `ЕД_ГРАДУС`, `ЕД_ПРОЦЕНТ`.

---

### ОПЦИОНАЛЬНЫЕ / РЕЗУЛЬТАТ

`Нечто` / `Ничто`, `Успех` / `Ошибка` (ядро + проверки `—`).

```zip
результат = найти(массив, значение)

если (результат — Нечто) {
    печать_число(нечто_значение(результат))
} иначе если (результат — Ничто) {
    печать_строки("Не найдено")
}

деление = делить(10, 0)
если (деление — Ошибка) {
    печать_строки(ошибка_текст(деление))
}
```

## Полный пример

```zip
#зависимость("нейросети = 1.0")
#зависимость("тензоры = 1.0")

@ускорить(уровень = 3)
функция обработать(вход) {
    слой1 = создать_слой(2, 4)
    слой2 = создать_слой(4, 1)
    h = прямой_проход_слоя(слой1, вход)
    возврат(прямой_проход_слоя(слой2, h))
}

функция главная() {
    вход = создать_тензор(1, 2, 0, 0)
    заполнить_тензор(вход, 2, 1, 0.5)
    результат = обработать(вход)
    печать_число(результат)
}
```
