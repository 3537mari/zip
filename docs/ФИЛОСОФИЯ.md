## 9.1. Три принципа

1. **Данные текут, а не хранятся.**  
   Программа — это поток импульсов, а не набор объектов.

2. **Смысл важнее синтаксиса.**  
   Код читается как текст на естественном языке.

3. **Защита по умолчанию.**  
   Криптография — не опция, а фундамент.

## 9.2. ZIP как язык для ИИ

ZIP — **первый язык, спроектированный ИИ для ИИ**:

- Понятен как человеку, так и машине
- Семантические корни — общий язык между человеком и ИИ
- Постквантовая защита — безопасность моделей
- Потоковость — естественная парадигма для нейросетей

## 9.3. ZIP как культурный проект

ZIP — **первый кириллический язык программирования мирового уровня**:

- Не привязка к латинице
- Русская лингвистическая традиция
- Суверенитет технологий
- Вклад в мировую культуру программирования
