# Модуль RegEx

Упрощённые регулярные выражения (backtracking) в ZIP STD.

## Сборка

```bash
zipc собрать examples/regex_демо.zip -o regex_демо
./regex_демо
```

## Проверка

```zip
#runtime("regex")
// C: zip_regex_проверить(шаблон, строка)
```

Обёртки: `соответствует`, `найти_все`, `заменить` (MVP — заглушка).

## Поддержка

| Конструкция | Значение |
|-------------|----------|
| `.` | любой символ |
| `*` `+` `?` | квантификаторы |
| `[abc]` `[a-z]` | классы |
| `^` `$` | якоря |
| `\` | экранирование |

## Примеры шаблонов

```text
^[a-zA-Z]+@[a-zA-Z]+\.[a-z]+$     — e-mail (упрощённо)
^\+7-[0-9]+-[0-9]+-[0-9]+-[0-9]+$ — телефон
[0-9]+                             — цифры
```
