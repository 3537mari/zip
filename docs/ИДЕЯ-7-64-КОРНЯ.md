# Идея 7. 64 корня — полная таблица кодонов

## Основание

В ДНК 64 кодона (4³). В ZIP — 64 корня для полного
покрытия языковых примитивов.

## Категории

### 1. Базовые (20)

СПР, ЧТВ, ПХД, ЖВТ, СГН, ТРГ, ЦПЬ, СЮЗ, ВДТ, КРП,
МЗГ, РЗМ, ПРЦ, ЛГК, ДТЧ, НТЛ, ВРМ, МСТ, СБТ, ЗПС

### 2. Глаголы высшего порядка (10)

КМД, УПР, КНТ, НБЛ, АНЛ, СНТ, ПРГ, ОПТ, АДП, ЭВЛ

### 3. Типы данных (10)

ЧСЛ, СТР, МСС, СТК, ФЛГ, ВКТ, МТЦ, КРТ, ОЧР, СТБ

### 4. Модификаторы (10)

БЗП, СКР, ПБЛ, СТТ, ДНМ, АСН, СНХ, КНС, ИЗМ, ЛКЛ

### 5. Специальные (14)

ТСТ, ЛГР, МТР, ПРФ, КШР, ТРН, РЗВ, ТАЙ, КЛБ, СНЦ,
БАР, СМФ, МТК, КНЛ

> `СНЦ` — специальная синхронизация (отдельно от модификатора `СНХ`).

## Полный пример

```zip
// Все категории в одной программе
СПР = { А-А: САПАР }        // базовый
КМД = { А-А: КАМАД }        // глагол высшего порядка
СТР = { А-А: САТАР }        // тип данных
КНС = { А-А: КАНАС }        // модификатор
ТСТ = { А-А: ТАСТ }         // специальный
```

## API

Модуль `zipc::корни`:

- `полная_таблица()` → 64 записи
- `найти_корень("СПР")` / `корни_по_категории(...)`
- `известный_код` / `валидный_код_корня`
