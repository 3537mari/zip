# КОРНИ ZIP

Словарь семантических корней языка ZIP.  
Источник: структура документации в [МАСТЕР-ПЛАН.md](../МАСТЕР-ПЛАН.md) §3.2 и таблица корней из [АЛФАВИТ.md](АЛФАВИТ.md).

## Модель корня

- **Корень** — три согласные буквы, семантическое ядро (СПР = счёт, ЧТВ = память, ЖВТ = жизнь).
- **Шаблоны гласных** — модификаторы формы:
  - **А-А** — процесс / глагол
  - **И-А** — буфер
  - **О-О** — инструмент

## Объявление корня в коде

```zip
СПР = { А-А: САПАР, И-А: СИПРА, О-О: СПОРО }
МЗГ = { А-А: МАЗАГ, И-А: МИЗГА, О-О: МОЗГО }
```
