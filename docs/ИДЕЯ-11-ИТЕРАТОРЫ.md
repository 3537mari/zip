# Идея 11. Итераторы Ы

## Основание
Буква `Ы` обозначает множественность в русском языке.
Шаблон `Ы-А` создаёт итератор (`ТипШаблона::Итератор` → `Тип::Итератор`).

## Синтаксис
```zip
массив = СИПРА(10)
СИПРА_добавить(массив, 1)
СИПРА_добавить(массив, 2)

для элемент в СЫПРА_из_СИПРА(массив) {
    ПечатьЧисло(элемент)
}

// Совместимость с диапазонами (Идея 10):
для и в 0..N {
    ПечатьЧисло(и)
}
```

## Протокол
Цикл `для x в <итератор>` разворачивается в IR:

1. `ит = <выражение>`
2. `пока (__iter_has_next(ит)) { x = __iter_next(ит); тело }`

Runtime (`zip-std/runtime/iter.c`, `#runtime("iter")`):

| C | ZIP |
|---|-----|
| `zip_создать_итератор` | `СЫПРА` / `СЫПРА_из_СИПРА` |
| `zip_есть_следующий` | `__iter_has_next` |
| `zip_следующий` | `__iter_next` |

## Применение
- Перебор массивов
- Фильтрация
- Преобразование (map/filter/reduce)
- Ленивые вычисления
