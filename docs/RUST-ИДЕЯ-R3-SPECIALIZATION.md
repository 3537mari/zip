# R3. Specialization — специализация глаголов по типам

## Основание

В Rust — специализация трейтов (Project Goal).
В ZIP — несколько реализаций одного глагола для разных типов.

## Синтаксис

```zip
глагол САПАР(а: Целое, б: Целое) -> Целое {
    возврат(а + б)
}

глагол САПАР(а: Тензор, б: Тензор) -> Тензор {
    возврат(матричное_умножение(а, б))
}

глагол САПАР(а: Строка, б: Строка) -> Строка {
    возврат(соединить_строки(а, б))
}
```

## Как работает

1. Последовательные объявления `глагол ИМЯ(...)` с одним именем собираются в `Узел::СпециализацияГлагола`.
2. Для каждого варианта создаётся отдельная IR-функция (`ИМЯвариант0`, …).
3. На месте вызова компилятор сопоставляет типы аргументов (из типов регистров) с `типы_параметров` вариантов.
4. Вызывается подходящий вариант; если совпадений нет — ошибка компиляции (и runtime-хелпер `zip_ошибка_типа` для отложенных случаев).

## Применение

- Полиморфизм без наследования
- Оптимизация (быстрые пути для конкретных типов)
- Адаптация под железо (разные реализации для AVX2/AVX-512)
- Обратная совместимость (добавление новых типов без ломки старого кода)
