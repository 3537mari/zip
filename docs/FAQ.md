# ZIP — Часто задаваемые вопросы

## Общие вопросы

### Что такое ZIP?

ZIP (Zero-Immunity-Pulse) — императивный потоковый язык
программирования на кириллице. Программа — семантический поток
действий (VSO), а не набор объектов.

### Почему только кириллица?

Это уникальная особенность ZIP:

- лингвистическая автономия (не привязка к латинице);
- семантические корни (`СПР` = счёт, `ЧТВ` = память);
- мнемоничность (код читается ближе к тексту);
- ориентир для русскоязычных разработчиков и ИИ.

### Насколько ZIP быстрый?

Ориентиры (зависят от CPU и сборки):

- LLVM-бэкенд ≈ **19×** быстрее внутреннего ASM-пути;
- GEMM 512×512 ≈ **4.2×** относительно NumPy;
- обучение XOR — порядка десятков миллисекунд.

Подробнее: [ПРОИЗВОДИТЕЛЬНОСТЬ.md](ПРОИЗВОДИТЕЛЬНОСТЬ.md).

### Зачем ZIP, если есть Rust / Python?

ZIP занимает свою нишу:

- **кириллица** — код и семантика на русском;
- **потоковость** — `>>`, `||`, агенты и потоки данных;
- **ИИ-примитивы** — тензоры, нейросети в STD;
- **владение импульсами** — анализ в духе Polonius;
- **постквантовая / сильная криптография** в runtime;
- **самокомпиляция** и экосистема пакетов (`зипм`).

### Можно ли использовать ZIP для production?

**Да.** ZIP v1.0.0 стабилен; линия v1.1.0 добавляет документацию и оптимизации:

- самокомпиляция (fixed point);
- 200+ зелёных тестов;
- экосистема (LSP, отладчик, профилировщик, `зипм`);
- STD (тензоры, нейросети, сеть, крипто).

### Какая текущая версия?

**v1.1.0** — документация и производительность поверх стабильного ядра v1.0.0.
См. [CHANGELOG](../CHANGELOG.md), [ROADMAP](../ROADMAP.md).

## Установка и настройка

### Как установить ZIP?

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
export PATH="$PWD/zipc/target/release:$PATH"
```

Windows (PowerShell):

```powershell
$env:PATH = "$PWD\zipc\target\release;$env:PATH"
```

### Какие требования?

- Rust 1.75+
- LLVM 17+ (`clang` в `PATH`)
- Git
- Windows / Linux / macOS

### Как настроить IDE?

1. Установите VS Code или Cursor
2. Установите расширение `vscode-zip`
3. Укажите путь к LSP (`зип-lsp`)

### Как проверить версию?

```bash
zipc версия
# zipc 0.1.0  (релиз языка — v1.1.0)
```

## Язык

### Как объявить переменную?

```zip
имя = значение
возраст = 25
температура = 36.6
имя_строки = "Иван"
```

### Как объявить функцию?

```zip
функция имя(параметр1, параметр2) {
    возврат(результат)
}
```

### Как объявить корень?

```zip
СПР = {
    А-А: САПАР,    // глагол
    И-А: СИПРА,    // буфер
    О-О: СПОРО     // инструмент
}
```

### Как работает `>>`?

`>>` — импульс. Передаёт значение с семантикой владения
(move): данные «текут» по конвейеру без лишнего копирования.

### Что такое PERFECT?

Состояние после `!` — данные **неизменяемы**:

```zip
САПАР(данные) >> ЧАТАВ!
// результат — PERFECT
```

### Что такое IMPERFECT?

Состояние потока по умолчанию — данные можно изменять дальше.

### Как работают аннотации?

```zip
@ускорить(уровень = 3)
@кэшировать(размер = 1024)
@шифровать(алгоритм = "AES-GCM")
функция обработать(данные) {
    возврат(данные)
}
```

Полный список: [Справочник — аннотации](СПРАВОЧНИК.md#аннотации).

## Компиляция и запуск

### Как скомпилировать программу?

```bash
zipc собрать программа.zip -o программа --llvm
```

### Как запустить программу?

```bash
zipc запустить программа.zip --llvm
./программа   # после сборки (-o)
```

### Как скомпилировать с оптимизацией?

```bash
zipc собрать программа.zip -o программа --llvm -O3
```

### Что такое `--llvm`?

LLVM-бэкенд (`.ll` → `clang -O3`). Рекомендуется для production —
существенно быстрее ASM-пути.

### Что такое `.zipc`?

Байт-код для `zip-vm`:

```bash
zipc собрать программа.zip --байткод
zip-vm программа.zipc
```

### Как посмотреть IR?

```bash
zipc собрать программа.zip --вывод-пп
```

### Как посмотреть ассемблер?

```bash
zipc собрать программа.zip --вывод-ассемблера
```

### Что такое самокомпиляция?

ZIP компилирует сам себя (fixed point):

```bash
zipc zip-self/нативный.zip -o selfc --llvm
./selfc zip-self/нативный.zip selfc2
# артефакты совпадают при успешном bootstrap
```

См. [САМОКОМПИЛЯЦИЯ.md](САМОКОМПИЛЯЦИЯ.md).

## Ошибки и отладка

### Программа не компилируется. Что делать?

1. Проверьте синтаксис:
   ```bash
   zipc собрать программа.zip --только-парсинг
   ```
2. Откройте файл в VS Code/Cursor с `зип-lsp` — ошибки подсветятся.
3. Минимальный воспроизводимый пример — в [Issues](https://github.com/3537mari/zip/issues).

### Как отладить программу?

1. Откройте в VS Code / Cursor
2. Точка останова (`F9`)
3. Запуск отладчика (`F5`) — DAP через `зип-отладчик`

### Программа медленная. Что делать?

1. Профилируйте: `зип-профиль программа.zip --топ 20`
2. Аннотации: `@ускорить`, `@пластичность`, `@кэшировать`
3. Собирайте с `--llvm` (и при необходимости `--simd`)

### Ошибка «неизвестный символ» / латиница?

Идентификаторы — только кириллица:

```zip
// неверно
let x = 5

// верно
х = 5
```

### Ошибка «неизвестная аннотация»?

Проверьте список: `@пластичность`, `@comptime`, `@ускорить`,
`@кэшировать`, `@шифровать`, `@параллелить`, `@сон`, `@тест`,
`@нейрогенез`, `@проверить_шаблон`.

### Ошибка «не найдена библиотека»?

```bash
зипм добавить тензоры 1.0
зипм установить
```

Либо убедитесь, что `clang` / OpenSSL доступны для нужного `#runtime`.

## Экосистема

### Что такое `зипм`?

Менеджер пакетов (аналог Cargo/npm):

```bash
зипм создать пакет
зипм добавить <имя>
зипм установить
зипм опубликовать
```

### Что такое `зип-lsp`?

Language Server: автодополнение, диагностика, go-to-definition,
ассоциации.

### Что такое `зип-отладчик`?

DAP-адаптер для отладки в VS Code/Cursor (`F5`).

### Что такое `зип-профиль`?

Профилировщик (Callgrind / flamegraph):

```bash
зип-профиль программа.zip --топ 20 --svg flamegraph.svg
```

Подробнее: [ЭКОСИСТЕМА.md](ЭКОСИСТЕМА.md).

## ИИ и нейросети

### Как создать нейросеть?

```zip
#зависимость("нейросети = 1.0")

слой1 = создать_слой(2, 4)
слой2 = создать_слой(4, 1)
вход = создать_тензор(1, 2, 0, 0)
h = прямой_проход_слоя(слой1, вход)
выход = прямой_проход_слоя(слой2, h)
```

### Как обучить нейросеть?

```zip
для эпоха в 0..10000 {
    выход = прямой_проход_слоя(слой, вход)
    ошибка = ожидаемое - выход
    обратный_проход_слоя(слой, ошибка, скорость_обучения)
}
```

См. примеры в `zip-std/примеры/`.

### Что такое `@нейрогенез`?

Автогенерация композитов из повторяющихся паттернов IR:

```zip
@нейрогенез(порог = 5, паттерн = "САПАР")
функция пайплайн(данные) {
    а = САПАР(данные)
    б = САПАР(а)
    в = САПАР(б)
    возврат(в)
}
```

### Что такое `@comptime`?

Вычисления на этапе компиляции — результат может быть свёрнут
в константу в бинарнике.

### Что такое `@тест`?

Автогенерация тестов:

```zip
@тест(случай = 100, диапазон = "0..1000", границы = да)
функция сложить(а, б) -> Целое {
    возврат(а + б)
}
```

```bash
zipc тест программа.zip --llvm
```

## Производительность

### Насколько быстрый ZIP?

| Операция | ZIP (ориентир) | Эталон | Ускорение |
|----------|----------------|--------|-----------|
| Цикл 10⁹ | ~0.11 s | ~2.13 s (ASM-путь) | **~19×** |
| GEMM 512×512 | быстрее NumPy | NumPy | **~4.2×** |
| XOR обучение | ~десятки мс | — | — |
| JIT (горячие) | прирост | интерпретатор | ~×1.5+ |
| Memory pooling | парсинг | без пула | ~×1.27 |

Цифры зависят от CPU; снимайте через `зип-профиль` и `cargo bench`.

### Что такое `@пластичность`?

Порог «горячести»: после N вызовов функция может уйти в JIT
и агрессивные оптимизации.

### Что такое JIT?

Just-In-Time: горячие функции байт-кода компилируются в нативный
код (`clang -shared`). Параллельный JIT — при очереди ≥ 2 функций.

### Что такое Memory Pooling?

Bump-arena блоками по 64 КБ для снижения аллокаций при разборе.

## Безопасность

### Как защитить данные?

```zip
@шифровать(алгоритм = "AES-256-GCM")
функция обработать_пароль(пароль) {
    возврат(пароль)
}
```

Также: `#runtime("crypto")`, `хеш_sha256_hex`, AES-GCM API.

### Что такое постквантовая криптография?

Схемы, устойчивые к атакам квантовых компьютеров.
В ZIP заложены направления LWE / сильные примитивы в runtime —
смотрите модуль крипто и документацию `zip-std`.

### Как проверить целостность?

```zip
хеш = хеш_sha256_hex(данные, длина)
// сравнить с эталоном
```

## Философия

### Почему «ZIP»?

**ZIP** (Zero-Immunity-Pulse):

- **Z** — Zero (нулевое / чистое состояние)
- **I** — Immunity (иммунитет / защита)
- **P** — Pulse (импульс / потоковость)

### Почему биологические параллели?

Вдохновение: ДНК (64 кодона → корни), нейроны (импульсы, пластичность),
мозг (ассоциации). См. [БИОЛОГИЯ.md](БИОЛОГИЯ.md), [ФИЛОСОФИЯ.md](ФИЛОСОФИЯ.md).

### Какое будущее у ZIP?

См. [ROADMAP.md](../ROADMAP.md): v1.1 ✅, далее STD-модули, хостинг реестра,
плагины редакторов, v2.0 — свой байт-код и верификация.
