# Идея 8. Гласные как модификаторы типа

## Основание

В семитских языках гласные меняют форму корня (мишкаль). В ZIP
10 гласных кириллицы = 10 семантических типов для каждого скелета.

## Таблица

| Гласная | Тип | Пример | Применение |
|---------|-----|--------|------------|
| А | Процесс | САПАР | Глагол счёта |
| Е | Свойство | СЕПАР | Чётность / признак |
| Ё | Особая форма | СЁПАР | Точный / акцентный счёт |
| И | Множество | СИПРА | Массив / буфер |
| О | Инструмент | СПОРО | Процессор |
| У | Указатель | СУПРА | Ссылка / адрес |
| Ы | Итератор | СЫПРА | Перебор коллекции |
| Э | Эфемерное | СЭПРА | TTL / временное |
| Ю | Единица | СЮПРА | Единица измерения |
| Я | Ядро | СЯПРА | Ядро / центр |

## Объявление корня

```zip
СПР = {
    А-А: САПАР, Е-А: СЕПАР, Ё-А: СЁПАР, И-А: СИПРА, О-О: СПОРО,
    У-А: СУПРА, Ы-А: СЫПРА, Э-А: СЭПРА, Ю-А: СЮПРА, Я-А: СЯПРА
}
```

Компилятор заполняет `по_типу: HashMap<ТипШаблона, String>` и
задаёт `Тип` возвращаемого значения stub-функций по мишкалю.

## API

```rust
zipc::тип_шаблона("СИПРА")           // Some(Множество)
zipc::определить_тип_по_гласным("Ы", "А") // Some(Итератор)
zipc::ШАБЛОНЫ                        // &[ (char, ТипШаблона); 10 ]
```
