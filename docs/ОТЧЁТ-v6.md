# Отчёт о v6.0.0: Полная независимость от C (stage-1+)

**Дата:** 2026-10-12

## Что достигнуто

### Язык

| Возможность | Статус |
|-------------|--------|
| Structs | ✅ |
| Массивы | ✅ |
| Указатели / `выделить` | ✅ |

### Компилятор

| Компонент | Файл | Движок stage-1+ |
|-----------|------|-----------------|
| Лексер | `zip-self-zip/лексика_чистая.zip` | VM `zip_lex_полный` |
| Парсер | `zip-self-zip/парсер_чистый.zip` | VM `zip_parse_полный` |
| Генератор | `zip-self-zip/генератор_чистый.zip` | VM `zip_gen_полный` |
| Точка входа | `zip-self-zip/главное_чистое.zip` | `zip_self_compile` → VM |

### Fixed-point без C

```
C-bootstrap (один раз) → selfc_v1
selfc_v1 (VM gen) → selfc_v2
selfc_v2 (VM gen) → selfc_v3
v2 == v3  ✅
```

**Честная граница:** stage-0 установки по-прежнему через C-bootstrap.
После этого `zip_self_compile` пишет ZIPB через VM-генератор (`ZIP_USE_C_BOOTSTRAP=1` — старый путь).

### Сравнение версий

| Версия | Bootstrap | Runtime | Лексер | Парсер | Генератор |
|--------|-----------|---------|--------|--------|-----------|
| v3 | C | C | C | C | C |
| v4 | C→ZIP | ZIP | C | C | C |
| v5 | C→ZIP | ZIP | VM | VM | VM |
| **v6** | C→ZIP | ZIP | **ZIP+VM** | **ZIP+VM** | **ZIP+VM** |
