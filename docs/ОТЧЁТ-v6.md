# Отчёт о v6.1.0: Полный lowering в ZIP-байткод

**Дата:** 2026-10-12

## Что достигнуто

### Компоненты на чистом ZIP

| Компонент | Файл | Тесты |
|-----------|------|-------|
| Лексер | `zip-self-zip/лексика_чистая.zip` | ✅ |
| Парсер | `zip-self-zip/парсер_чистый.zip` | ✅ |
| Генератор | `zip-self-zip/генератор_чистый.zip` | ✅ |
| Точка входа | `zip-self-zip/главное_чистое.zip` | ✅ |
| Runtime | `zip-std/syscalls.zip` и др. | ✅ |
| STD | `zip-std/*.zip` | ✅ |

### Rust-VM — только интерпретатор

| Компонент | Язык | Роль |
|-----------|------|------|
| Лексер | **ZIP** | Алгоритм |
| Парсер | **ZIP** | Алгоритм |
| Генератор ZIPB | **ZIP** | Алгоритм |
| VM | Rust | **Интерпретатор ZIP-байткода** |
| C-bootstrap | C | **Stage-0 (один раз)** |

### Fixed-point без Rust-функций компилятора

```
C-bootstrap (один раз) → selfc_v1
selfc_v1 (ZIP-алгоритм в VM) → selfc_v2
selfc_v2 (ZIP-алгоритм в VM) → selfc_v3
selfc_v3 → selfc_v4
v2 == v3 == v4  ✅  (03ec79b9...C6A98C59)
v1 ≠ v2         ожидаемо (C stage-0 vs ZIP-генератор)
```

- Fixed-point достигается **через ZIP-алгоритм**, а не через Rust
- `zip_self_lex` / `zip_self_parse` / `zip_self_gen` — только маркеры

### Ключевые фиксы v6.1.0

- Постфикс `[` для корней/шаблонов (`виды[поз[0]]`)
- `CallNative` берёт арность сверху стека
- C-bootstrap: `POP` после statement-CALL

## Установка v6.1.0

```bash
# Один раз с C
cd bootstrap && make && cd ..
cargo build --release --manifest-path zip-vm/Cargo.toml

# Компиляция ZIP-компилятора
./bootstrap/zipc zip-self-zip/главное_чистое.zip /tmp/selfc_v1.zipb

# Самокомпиляция
./zip-vm/target/release/zip-vm /tmp/selfc_v1.zipb \
    zip-self-zip/главное_чистое.zip /tmp/selfc_v2.zipb
./zip-vm/target/release/zip-vm /tmp/selfc_v2.zipb \
    zip-self-zip/главное_чистое.zip /tmp/selfc_v3.zipb

# Fixed-point
sha256sum /tmp/selfc_v2.zipb /tmp/selfc_v3.zipb
# 03ec79b9...C6A98C59
```
