# Отчёт о v5.0.0: Конвейер компилятора в VM

**Дата:** 2026-10-12

## Что достигнуто

### Компоненты в VM (Rust)

| Компонент | Файл | Статус |
|-----------|------|--------|
| Лексер | `zip-vm/src/zip_lex_полный.rs` | ✅ |
| Парсер | `zip-vm/src/zip_parse_полный.rs` | ✅ |
| AST | `zip-vm/src/zip_ast.rs` | ✅ |
| Генератор | `zip-vm/src/zip_gen_полный.rs` | ✅ |

### Полная цепочка

```
.zip → лексер (VM) → парсер (VM) → генератор (VM) → .zipb
```

CLI: `zip-vm --gen программа.zip > программа.zipb`

### Тесты

Лексер / парсер / генератор / цепочка — зелёные (см. `tests/тест_*_zip.rs`).

## Честная граница

| Сделано | Не сделано (→ v6) |
|---------|-------------------|
| Алгоритмы lex/parse/gen в VM без вызова C | Lowering алгоритмов в ZIP-байткод |
| Stage-0 всё ещё C-bootstrap для установки | Убрать C полностью |
| ZIPB совместим по магии/структуре | Байт-в-байт с C |

## Сравнение

| Версия | Bootstrap | Лексер | Парсер | Генератор |
|--------|-----------|--------|--------|-----------|
| v3 | C | C | C | C |
| v4 | C→ZIP API | C | C | C |
| **v5** | C→ZIP API | **VM** | **VM** | **VM** |
| v6 (план) | ZIP | ZIP | ZIP | ZIP |
