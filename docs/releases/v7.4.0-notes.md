# ZIP v7.4.0 — AES-256-GCM на чистом ZIP

## Что нового

### AES-256-GCM — на чистом ZIP
- S-box, key expansion, шифрование блоков (AES-256)
- GCM: CTR + GHASH
- Constant-time сравнение
- **NIST test vectors совпадают**

- VM builtins `zip_crypto_aes_encrypt` / `decrypt` удалены
