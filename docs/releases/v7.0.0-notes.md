## Что нового

### Windows ARM64
- Rust-VM собирается под `aarch64-pc-windows-msvc`
- CI: нативный runner `windows-11-arm` + cross-build на `windows-latest`
- ZIPB идентичен x86-64 (`03ec79b9...c6a98c59`)

### Платформонезависимость на всех целях v7
- x86-64 (Linux, Windows, macOS)
- ARM64 (Linux, macOS, **Windows**)
- RISC-V 64
- WASM (браузер)

### v7.0.0 полностью закрыт
Все платформы поддержаны. Компилятор ZIP написан на ZIP. Fixed-point сохранён.
