## Что нового

### Криптография без OpenSSL
- SHA-256 / SHA-3 ✅ (`zip-crypto`)
- **AES-256-GCM** ✅ (NIST vectors)
- **Kyber-1024 / ML-KEM-1024** ✅ (KEM round-trip)
- **Dilithium-5 / ML-DSA-87** ✅ (подпись / проверка)
- Constant-time сравнение ✅
- getrandom через OS CSPRNG ✅

### Интеграция
- ZIP STD: `крипто.zip`, `крипто_aes.zip`, `крипто_kyber.zip`, `крипто_dilithium.zip`
- VM builtins: `шифровать_аес`, `kyber1024_*`, `dilithium5_*`, …
- `@шифровать(алгоритм = "AES-256-GCM")` → LLVM declare ZIP-crypto
- `zip-std/runtime/crypto.c` больше **не** зависит от OpenSSL
