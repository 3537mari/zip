## Что нового

### Полный lowering в ZIP-байткод
- Лексер на чистом ZIP (лексика_чистая.zip)
- Парсер на чистом ZIP (парсер_чистый.zip)
- Генератор ZIPB на чистом ZIP (генератор_чистый.zip / главное_чистое.zip)
- zip_self_lex / zip_self_parse / zip_self_gen — только маркеры

### Fixed-point без Rust-функций компилятора
- v2 = v3 (SHA-256 совпадает)
- ZIP-ядро: лексер + парсер + генератор на ZIP
- Rust-VM — интерпретатор + runtime builtins

### Исправления
- Постфикс [/вызов для корней и шаблонов (вложенный индекс [b[0]])
- CallNative учитывает арность (байтбуферы)
- C-bootstrap: POP после statement-CALL
