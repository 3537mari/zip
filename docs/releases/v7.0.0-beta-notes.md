## Что нового

### RISC-V 64
- Rust-VM собирается под `riscv64gc-unknown-linux-gnu`
- ZIP-байткод платформонезависим — один и тот же `.zipb` работает везде
- CI: `.github/workflows/riscv.yml` — сборка и тесты через QEMU

### Платформонезависимость на 3 ISA
- x86-64 (Linux, Windows, macOS)
- ARM64 (Linux, macOS, Windows targets)
- RISC-V 64
- selfc даёт идентичный `.zipb` (`03ec79b9...c6a98c59`)
