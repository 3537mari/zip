## Что нового

### iOS (Swift + Objective-C bridge)
- Rust-VM → `libzip_vm_ios.a` (`aarch64-apple-ios`, sim arm64 / x86_64)
- `ZipVM.xcframework` — устройство + universal simulator (lipo)
- C-API: `zip_compile`, `zip_run`, `zip_compile_and_run`, `zip_free`, `zip_version`
- Swift: `Zip.compile`, `Zip.run`, `Zip.compileAndRun`, `Zip.version`
- Демо SwiftUI + тесты на симуляторе
- CI: `.github/workflows/ios.yml`
- Требования: iOS 13.0+ (Swift 5.9+)

### Платформонезависимость
x86-64 · ARM64 (Linux/macOS/Win) · RISC-V · WASM · Android · **iOS**
