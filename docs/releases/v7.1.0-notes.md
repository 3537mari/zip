## Что нового

### Android (NDK + JNI)
- Rust-VM → `libzip_vm_android.so` (`aarch64-linux-android`, `x86_64-linux-android`)
- Kotlin API: `Zip.скомпилировать`, `Zip.запустить`, `Zip.скомпилироватьИЗапустить`, `Zip.версия`
- Демо APK + instrumentation-тесты
- CI: `.github/workflows/android.yml`
