## Что нового

### ARM64
- Rust-VM собирается под ARM64 (Linux, macOS, Windows targets)
- ZIP-байткод платформонезависим — один и тот же `.zipb` работает везде
- CI: `.github/workflows/arm64.yml` — сборка и тесты ARM64 через QEMU
- `zip-vm --target …` — информационный флаг

### Платформонезависимость
- Компилятор (`selfc.zipb`) — тот же, что на x86-64 (v6.1.0 fixed-point)
- На ARM64 через QEMU ожидается идентичный `.zipb` (`03ec79b9...`)
