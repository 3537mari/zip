## Что нового

### WASM (WebAssembly)
- Rust-VM собирается под `wasm32-unknown-unknown` + `wasm-bindgen`
- Web-совместимый backend (без `std::process`, без файлов)
- Плейграунд: компилировать **и запускать** ZIP в браузере
- API: `compileZip`, `runZip`, `compileAndRun`, `versionZip`
- CI: `.github/workflows/wasm.yml` (headless Chrome)

### Платформы
- x86-64 · ARM64 · RISC-V 64 · **WASM**
- ZIPB платформонезависим (`03ec79b9...c6a98c59`)
