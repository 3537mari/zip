# ZIP v7.6.0 — GPU через wgpu (Vulkan)

## Что нового

- Кросс-платформенный GPU: Intel / NVIDIA / AMD / Apple Silicon
- WGSL-шейдер GEMM
- Приоритет: wgpu → CUDA → CPU
- Проверено на Intel UHD Graphics (Vulkan 1.2)

## Сборка

```bash
cargo build --release --manifest-path zip-vm/Cargo.toml --features gpu
```
