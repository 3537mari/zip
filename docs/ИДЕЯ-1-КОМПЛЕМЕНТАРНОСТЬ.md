# Идея 1. Комплементарные корни

## Основание
В ДНК A-T, G-C комплементарны. В ZIP каждый корень имеет обратный.

## Правило
Обратный корень = перестановка 1-й и 3-й согласных.

| Прямой | Обратный |
|--------|----------|
| СПР | РПС |
| ЧТВ | ВТЧ |
| ЖВТ | ТВЖ |

Комплементарный мишкаль: перестановка первой и последней согласных слова.

| Прямой | Обратный |
|--------|----------|
| САПАР | РАПАС |
| ЧАТАВ | ВАТАЧ |

При объявлении `СПР = { А-А: САПАР }` компилятор автоматически регистрирует `РАПАС`.

## Применение
- Автоматические undo/redo
- Транзакции с откатом (`zip-std/runtime/undo.c`, `#runtime("undo")`)
- Двунаправленные преобразования

## API
```rust
zipc::обратный_корень("СПР")   // Some("РПС")
zipc::обратный_глагол("САПАР") // Some("РАПАС")
```
