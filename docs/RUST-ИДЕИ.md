# Идеи из Rust для ZIP

## ЧАСТЬ XIII. 7 ИДЕЙ ИЗ RUST ДЛЯ ZIP

### Идея R1. Polonius (улучшенный borrow checker) ✅

Точное отслеживание владения импульсами `>>` на этапе компиляции
(см. [RUST-ИДЕЯ-R1-POLONIUS.md](RUST-ИДЕЯ-R1-POLONIUS.md)).

**Приоритет:** ✅ сделано (MVP) · **Этап:** 2

### Идея R2. Reflection and comptime 🔴

```zip
@comptime
функция вычислить_константу() {
    возврат(САПАР(1000000))
}
```

**Приоритет:** 🔴 высокий · **Этап:** 2

### Идея R3. Specialization — специализация глаголов

```zip
глагол САПАР(а: Целое, б: Целое) { /* ... */ }
глагол САПАР(а: Тензор, б: Тензор) { /* ... */ }
```

**Приоритет:** 🟡 средний · **Этап:** 2

### Идея R4. Range* types (Copy)

```zip
д = 0..100
д2 = д
для и в д { ... }
```

**Приоритет:** 🟡 средний · **Этап:** 2

### Идея R5. assert_matches!

```zip
@проверить_шаблон(результат, "Успех(_)")
```

**Приоритет:** 🟡 средний · **Этап:** 2

### Идея R6. Function overloading in FFI

```zip
#link("libc")
функция открыть(путь: Строка) -> Файл
функция открыть(путь: Строка, режим: Строка) -> Файл
```

**Приоритет:** 🟡 средний · **Этап:** 2

### Идея R7. cargo-script

```bash
zipc запустить скрипт.zip   # без зипм.манифест
```
