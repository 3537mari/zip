### Идея R1. Polonius (улучшенный borrow checker) ✅

Точное отслеживание владения импульсами `>>` на этапе компиляции
(см. [RUST-ИДЕЯ-R1-POLONIUS.md](RUST-ИДЕЯ-R1-POLONIUS.md)).

**Приоритет:** ✅ сделано (MVP) · **Этап:** 2

### Идея R2. Reflection and comptime ✅

```zip
@comptime
функция факториал(н) {
    если (н < 2) { возврат(1) } иначе { возврат(н * факториал(н - 1)) }
}
```

См. [RUST-ИДЕЯ-R2-COMPTIME.md](RUST-ИДЕЯ-R2-COMPTIME.md).

**Приоритет:** ✅ сделано (MVP) · **Этап:** 2
