# Генератор ZIPB в VM

## Цель

Перенести генерацию байт-кода из C-bootstrap в VM (Rust), затем — в чистый ZIP.

## Что сделано

### `zip-vm/src/zip_gen_полный.rs`

- Лексер → парсер → ZIPB v3
- Формат как `сериализовать_v3` / C-bootstrap: заголовок → строки → функции
- Прыжки по **индексу инструкций** (`ipc`), как в C
- Локали `LOAD`/`STORE`, `если`/`пока`/`для`, вызовы, `>>`/`!`

### CLI

```bash
./zip-vm/target/release/zip-vm --gen программа.zip > out.zipb
```

### Вызовы

- `zip_self_gen(исходник)` → `1`/`0`
- `zip_gen_полный(исходник)` → размер ZIPB или `-1`
- `zip_self_codegen` — тоже через VM-генератор

## Тесты

- `тест_генератора_zip`, `тест_паритет_генератор`, `тест_полной_цепочки_zip`
- unit-тесты в модуле генератора
