# Парсер ZIP в VM

## Цель v5.x

Перенести алгоритм парсера из C-bootstrap в VM (Rust), затем — в чистый ZIP.

## Что сделано

### AST (`zip-vm/src/zip_ast.rs`)

Программа, функции (аннотации, параметры, тип возврата), блоки, выражения,
инструкции (`если` / `пока` / `для` / `возврат`), поток, фиксация, директивы.

### Парсер (`zip-vm/src/zip_parse_полный.rs`)

Рекурсивный спуск с приоритетами как в C-bootstrap:

- хор `||` → пульс `>>`/`>>>` → или/и → сравнения → `+`/`-` → `*`/`/` → унарные → литералы/вызовы
- аннотации `@имя(ключ = значение)`
- `#runtime(...)`
- постфиксная фиксация `expr!`

### Внешний вызов

- `zip_self_parse(исходник)` → `1` / `0`
- `zip_parse_полный(исходник)` → число функций или `-1`
