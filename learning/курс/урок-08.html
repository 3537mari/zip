Урок 8: Агенты

Агенты хранят состояние и методы — удобно для сервисов и долгоживущих процессов.

агент Счётчик {
    состояние {
        н: Целое = 0
    }
    функция шаг() {
        н = н + 1
        возврат(н)
    }
}
