# Видео 2: Первая программа на ZIP

**Длительность:** 5 минут  
**Аудитория:** новички после установки

## Сценарий

### 00:00–00:40 — Введение

> «Напишем и запустим первую программу на ZIP: «Привет, мир!» и простую функцию.»

### 00:40–02:00 — Hello world

Создаём `привет.zip`:

```zip
ПечатьСтроки("Привет, мир!")
```

Запуск:
```bash
zipc запустить привет.zip
```

### 02:00–03:30 — Функция главная

```zip
функция главная() {
    ПечатьСтроки("Привет из главной!")
    ПечатьЧисло(2 + 3)
}
```

### 03:30–04:30 — Что происходит под капотом

> «Компилятор разбирает кириллический код, строит IR и либо запускает через runtime, либо собирает нативный бинарник.»
