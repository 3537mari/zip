# План записи видео

## Оборудование

- **Микрофон:** любой USB (Blue Yeti, Rode NT-USB)
- **Запись экрана:** OBS Studio (бесплатно)
- **Редактор:** DaVinci Resolve (бесплатно) или Kdenlive
- **Освещение:** окно или LED-панель

## Настройки OBS

| Параметр | Значение |
|----------|----------|
| Разрешение | 1920×1080 (Full HD) |
| FPS | 30 |
| Битрейт | 6000 kbps |
| Формат | MP4 |
