### 01:00–03:00 — Переменные и типы

```zip
функция главная() {
    а = 42
    имя = "ZIP"
    флаг = истина
    ПечатьЧисло(а)
    ПечатьСтроки(имя)
}
```

Упомянуть: целые, строки, флаги, вещественные.

### 03:00–05:00 — Условия и циклы

```zip
функция главная() {
    если (а > 0) {
        ПечатьСтроки("положительно")
    } иначе {
        ПечатьСтроки("нет")
    }
    для и в 0..5 {
        ПечатьЧисло(и)
    }
}
```

### 05:00–07:30 — Функции и возврат

```zip
функция сложить(а, б) {
    возврат(а + б)
}
```

### 07:30–09:00 — Импульс и потоки

```zip
САПАР(данные) >> ЧАТАВ!
```

> «`>>` — импульс (move), `!` — PERFECT, `||` — параллельный хор.»
