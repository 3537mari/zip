# Видео 1: Установка ZIP за 5 минут

**Длительность:** 5 минут  
**Аудитория:** новички  
**Ссылки в описании:** GitHub, документация, сайт

## Сценарий

### 00:00–00:30 — Введение

**Визуал:** логотип ZIP, фон с кириллицей  
**Голос:**
> «Привет! Сегодня установим ZIP — язык программирования на кириллице. Это займёт около пяти минут.»

### 00:30–01:30 — Требования

**Визуал:** список на экране  
> «Нужны: Rust (через rustup), clang/LLVM, Git. Windows, Linux и macOS поддерживаются.»

**Показ:** установка Rust (Windows — rustup-init; Unix — curl rustup).

### 01:30–03:00 — Клонирование и сборка

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
```

> «Клонируем репозиторий и собираем компилятор. Первая сборка может занять несколько минут.»

### 03:00–04:00 — PATH

**Windows (PowerShell):**
```powershell
$env:Path = "$PWD\zipc\target\release;$env:Path"
```

**Unix:**
```bash
export PATH="$PWD/zipc/target/release:$PATH"
```

### 04:00–04:30 — Проверка

```bash
zipc --help
zipc запустить examples/привет.zip
```

### 04:30–05:00 — Заключение

> «Готово. В следующем видео — первая программа. Ссылки в описании.»
