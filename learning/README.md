## Как использовать

### Видео

1. Прочитать сценарий  
2. Записать экран  
3. Смонтировать  
4. Загрузить на YouTube (описание из `youtube-описания.md`)

### Курс

1. Открыть `курс/index.html`  
2. Проходить уроки по порядку  
3. Экспериментировать в [плейграунде](../веб-сайт/плейграунд.html)

### Соцсети

1. Выбрать платформу и шаблон  
2. Адаптировать под аудиторию  
3. Приложить SVG при необходимости  
4. Опубликовать
