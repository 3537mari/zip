# Bootstrap ZIP на C

Полноценный компилятор ZIP на C. Используется для установки ZIP
без Rust и LLVM.

## Возможности

- **Лексер**: полная поддержка кириллицы (UTF-8), ключевые слова, операторы
- **Парсер**: функции, условия, циклы, приоритеты, вызовы
- **Генератор**: байт-код ZIPB v3
- **Fixed-point**: детерминированная перекомпиляция (одинаковый `.zipb`)

## Установка

```bash
# Linux/macOS
make

# Windows (clang / MinGW)
pwsh ./build.ps1
# или: make windows

# Windows (MSVC)
make msvc
```

## Использование

```bash
./zipc программа.zip программа.zipb
../zip-vm/target/release/zip-vm программа.zipb
```

## Самокомпиляция / fixed-point

```bash
# Детерминизм C-bootstrap (хеши совпадают)
./тесты/тест_fixed_point.sh          # Linux/macOS
pwsh ./тесты/тест_fixed_point.ps1    # Windows

# Компиляция selfc-заготовки (полный self-host — v4.0.0)
./zipc ../zip-self/компилятор.zip /tmp/selfc_c.zipb
```

## Архитектура

```
bootstrap/
├── zipb.h           — общие определения
├── утилиты.c        — память, буфер, узлы
├── таблицы.c        — ключевые слова, имена токенов
├── лексер.c         — кириллица UTF-8, операторы, литералы
├── парсер.c         — AST, приоритеты операторов
├── генератор.c      — байт-код ZIPB v3
├── дамп.c           — дизассемблер ZIPB
├── проверка.c       — валидация AST
├── главное.c        — CLI
└── тесты/
    ├── тест_самокомпиляции.sh
    ├── тест_fixed_point.sh / .ps1
    └── сравнить_с_rust.sh / .ps1
```

## Зависимости

Только C-компилятор:
- **Linux/macOS**: gcc или clang
- **Windows**: MinGW (gcc), clang или MSVC (cl)

Никакого Rust. Никакого LLVM.

## Размер

- MVP (v3.0.0): ~1000 строк C
- Текущий: ~1650 строк C (полный лексер/парсер/генератор ядра)
- Цель: ~5000 строк C (покрытие selfc, v3.x → v4)

## Сравнение с Rust-bootstrap

| Параметр | Rust | C |
|----------|------|---|
| Размер | ~50 000 строк | ~1650+ строк |
| Зависимости | Rust (+ LLVM опц.) | Только C |
| Установка | cargo build | make / build.ps1 |
| Скорость сборки | ~60 сек | ~5 сек |
| Размер бинарника | ~1.3 МБ | ~100 КБ |
