# ZIP-SELF: лексер (этап 1)

## Структура `лексика.zip`

- Константы видов токенов (`КОНЕЦ_ФАЙЛА`, `ЦЕЛОЕ`, …)
- Типы `Токен`, `Лексер` (в спецификации / runtime)
- `#runtime("lexer_zip")` → `лексика_rt.c` (clang -O3)

## Что уже работает (v1)

- Пропуск пробелов / табов / переводов строк
- Целые числа (`42`, `7`, `100`)
- Одиночные разделители: `= : ( ) { } ,`

## Оценка оставшегося объёма

| Блок | Доля | Статус |
|------|------|--------|
| Типы данных | 20% | спецификация готова |
| Память | 15% | через C runtime |
| UTF-8 / кириллица | 25% | stub (байт=слово) |
| КА лексера (слова, строки, `>>`, корни) | 40% | впереди |

Итого ~70% работы до паритета с Rust-лексером (`zipc/src/лексика.rs`).
