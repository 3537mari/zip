# ZIP: язык программирования на кириллице, который в ~40 раз быстрее Python

## Введение

Я задался вопросом: почему почти все языки программирования используют латиницу? Можно ли сделать язык с **семантическими корнями на кириллице**, где код читается ближе к естественному тексту — и при этом не жертвовать скоростью?

Так развился **ZIP** (Zero-Immunity-Pulse) — императивный потоковый язык. Сейчас вышел **v2.1.0**: профилированный компилятор, покрытие ядра тестами ~90%, бенчмарки, production-пример REST API.

## Что такое ZIP?

### Философия

**ZIP = Zero + Immunity + Pulse**

- **Zero** — данные текут, а не «лежат» в объектах по умолчанию  
- **Immunity** — криптозащита в STD (в т.ч. постквантовые примитивы)  
- **Pulse** — импульсная архитектура VSO (глагол → субъект/данные)

### Пример кода

```zip
функция сложить(а, б) {
    возврат(а + б)
}

функция главная() {
    результат = сложить(2, 3)
    ПечатьЧисло(результат)  // 5
}
```

## Уникальные особенности

### 64 семантических корня

Корень — три буквы, обозначающие концепцию (СПР — счёт, ЧТВ — память, ЖВТ — жизнь/создание и т.д.).

### 10 типов через гласные

Один корень + разные гласные → разные роли (глагол / буфер / инструмент / …).

### Потоковая парадигма

```zip
САПАР(данные) >> ЧАТАВ!
```

Оператор `>>` — **импульс**: перенос владения без копирования (близко к Move в Rust).  
Также: `||` (хор/параллель), `!` (PERFECT — фиксация), `~` (асинхронный поток).

## Производительность

### Бенчмарки (v2.1.0)

| Задача | ZIP | Python | Rust | Go |
|--------|-----|--------|------|-----|
| Fibonacci(40) | 1395 ms | 17883 ms | 336 ms | 723 ms |
| GEMM 512² | 24 ms | 3.5 ms (NumPy) | 216 ms* | 646 ms* |
| JSON 10k | 5 ms | 77 ms | 6.5 ms | 23 ms |
| Strings 1M | 64 ms | 1392 ms | 106 ms | 86 ms |
| HTTP parse 5M | 45 ms | 6519 ms | 42 ms | 56 ms |
| XOR 10k эпох | 7 ms | 333 ms | 8.7 ms | 5.8 ms |

\* naive-цикл в Rust/Go; у ZIP GEMM — оптимизированный STD runtime на clang.  
Подробности: [docs/БЕНЧМАРКИ.md](https://github.com/3537mari/zip/blob/master/docs/БЕНЧМАРКИ.md)

**Итог:** ZIP в среднем ~**40×** быстрее CPython; с Rust/Go — в одном классе, с оговорками по задаче.

### Почему быстро?

- LLVM / нативный путь и собственный байт-код ZIPB + VM v3  
- Move-семантика (без GC в горячем пути)  
- пулы памяти, SIMD-анализ, оптимизации компилятора

## Путь к независимости

| Версия | Bootstrap | LLVM | C-runtime | Зависимости |
|--------|-----------|------|-----------|-------------|
| v2.x | Rust | да (опц.) | да | Rust + LLVM + C |
| v3.0 | C | нет* | да | C |
| v4.0 | ZIP | нет | нет | только ОС |

\* LLVM остаётся опциональным путём максимальной производительности.
