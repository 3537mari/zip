# Твиттер / X — тред о ZIP

Публиковать по одному твиту (нумерация для удобства копирования).

---

**1/**  
Я сделал язык программирования только на кириллице.  
Он называется **ZIP** (Zero-Immunity-Pulse).  
v2.1.0 — production-ready.

**2/**  
Почему кириллица? Суверенитет синтаксиса.  
Почему быстро? LLVM + свой байт-код ZIPB + VM.

**3/**  
Бенчмарки (честно, со оговорками):  
~40× быстрее CPython  
часто рядом с Rust/Go  
в JSON/строках ZIP может обгонять Rust  

**4/**  
Фишки:  
• 64 семантических корня  
• 10 типов через гласные  
• потоки VSO  
• Move через `>>`  

**5/**  
ИИ в STD:  
тензоры, нейросети (XOR), агенты, потоки.

**6/**  
Формалка:  
семантика, теоремы, инструмент `zip-verify`.

**7/**  
Самокомпиляция:  
компилятор на ZIP, fixed point, ZIPB, своя VM.

**8/**  
Экосистема:  
зипм · зип-lsp · отладчик · профиль · VS Code/Neovim/Emacs.

**9/**  
Сайт: https://3537mari.github.io/zip/  
GitHub: https://github.com/3537mari/zip  
Релиз: https://github.com/3537mari/zip/releases/tag/v2.1.0

**10/**  
Дальше:  
v3 — убрать Rust bootstrap  
v4 — убрать C-runtime  
v5 — кросс-компиляция  

Пробуйте и ругайте конструктивно.
