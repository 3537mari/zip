**Title:** ZIP v6.0.0 — Fully self-hosted Cyrillic language (no C needed after bootstrap)

**Text:**

I'm thrilled to announce ZIP v6.0.0 — the Cyrillic programming language reaches stage-1+ self-hosting.

**What's new:**

- **Structs**, **arrays**, **pointers** in ZIP
- Compiler driver on ZIP (`zip-self-zip/*_чистая.zip`)
- Lex / parse / gen in the VM — no C after the one-time bootstrap
- Fixed-point: `selfc_v2` == `selfc_v3`
