## Как публиковать

### Hacker News

1. Открыть https://news.ycombinator.com/submit  
2. **Title:** `ZIP: A Cyrillic Programming Language That's 40× Faster Than Python`  
3. **URL:** `https://github.com/3537mari/zip` (или релиз / статья)  
4. При желании — текст из `hackernews.md` в комментарии к своему посту  

Альтернатива: **Show HN:** `Show HN: ZIP – Cyrillic PL, ~40× vs Python, ZIPB VM, TODO API`

### Reddit

Скопировать блоки из `reddit.md` в:

- https://www.reddit.com/r/programming/  
- https://www.reddit.com/r/rust/  
- https://www.reddit.com/r/compsci/  
- https://www.reddit.com/r/Python/ (осторожно с тоном)

Соблюдайте правила субреддитов (self-promo, flair).

### Habr

1. https://habr.com/ru/articles/  
2. Хабы: «Программирование», «Языки программирования», «Open source»  
3. Тело — `habr.md` (адаптировать под редактор Хабра)  

### Twitter / X

Копировать твиты из `twitter.md` по одному (или Thread tool).

### Конференция

Использовать `conference.md` как outline слайдов + демо-чеклист.

## Что важно

1. **Будьте готовы к критике** («зачем ещё язык?») — отвечайте суверенитетом, открытыми бенчмарками и формалкой.  
2. **Показывайте методологию** — ссылка на `docs/БЕНЧМАРКИ.md`, оговорки про NumPy/BLAS.  
3. **Ссылайтесь на документацию**, не объясняйте всё в посте.  
4. **Приглашайте к сотрудничеству** — issues / PRs welcome.  
5. **Не преувеличивайте** — на Fibonacci Rust быстрее; пишите «competitive», не «всегда быстрее Rust».
