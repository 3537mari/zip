# Доклад: ZIP — потоковый язык на кириллице

**Формат:** 25–40 мин + Q&A  
**Аудитория:** разработчики, исследователи PL, русскоязычные tech-конференции  
**Уровень:** intermediate

## Аннотация

ZIP (Zero-Immunity-Pulse) — императивный потоковый язык с кириллическим синтаксисом, Move-семантикой импульсов, ИИ-примитивами в STD и путём к полной самодостаточности (байт-код ZIPB, VM, компилятор на ZIP). В докладе — мотивация, модель языка, бенчмарки v2.1.0 и живой TODO REST API.

## Ключевые слайды (текст)

1. **Титул:** ZIP v2.1.0 — production-ready Cyrillic PL  
2. **Проблема:** латиница по умолчанию ≠ единственный путь  
3. **Философия:** Zero / Immunity / Pulse  
4. **Пример:** `функция сложить` + импульс `>>`  
5. **Архитектура:** zipc → LLVM | ZIPB → VM  
6. **Таблица бенчмарков** (из docs/БЕНЧМАРКИ.md)  
7. **TODO API** — схема клиент → сервер → JSON DB  
8. **Независимость:** v2 Rust → v3 C → v4 ZIP  
9. **Call to action:** GitHub, сайт, issues

## Возможные возражения и ответы

| Возражение | Ответ |
|------------|--------|
| «Зачем ещё язык?» | Суверенитет + другая модель потока + открытые бенчи |
| «Кириллица неудобна» | Для русскоязычных команд — читаемость; есть ASCII-алиасы API |
| «Rust быстрее на fib» | Да; смотрите JSON/strings/XOR; методология в репо |
| «Это просто обёртка над C» | STD runtime — как у многих языков; компилятор и IR — свои |
