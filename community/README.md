# Сообщество ZIP

## Каналы

| Платформа | Ссылка | Назначение |
|-----------|--------|------------|
| **Discord** | https://discord.gg/zip-lang | Общение, помощь |
| **Telegram-канал** | https://t.me/zip_lang_news | Анонсы |
| **Telegram-чат** | https://t.me/zip_lang_chat | Обсуждения |
| **GitHub Discussions** | https://github.com/3537mari/zip/discussions | Идеи, RFC |

> Ссылки Discord/Telegram — целевые; создайте сервер/каналы по чеклисту в [ЗАПУСК.md](ЗАПУСК.md) и обновите инвайты.

## Как присоединиться

1. Прочитайте [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)
2. Выберите платформу
3. Представьтесь в `#приветствие` (Discord)
