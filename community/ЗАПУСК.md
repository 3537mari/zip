# Запуск сообщества ZIP

## Шаг 1: Создать Discord

1. Открыть https://discord.com/create
2. Создать сервер «ZIP»
3. Настроить каналы по `community/discord/setup.md`
4. Настроить роли
5. Добавить ботов
6. Создать постоянную инвайт-ссылку

## Шаг 2: Создать Telegram

1. Создать канал `@zip_lang_news`
2. Создать группу `@zip_lang_chat`
3. Создать бота `@zip_lang_bot` (через BotFather)
4. Настроить команды бота (см. `telegram/бот.md`)

## Шаг 3: Настроить GitHub Discussions

1. Открыть https://github.com/3537mari/zip/settings
2. Включить Discussions
3. Настроить категории:
   - Объявления
   - Идеи
   - Вопросы
   - Покажи проект
4. Шаблоны уже в `.github/DISCUSSION_TEMPLATE/`

## Шаг 4: Опубликовать ссылки

Обновить в:

- `README.md`
- `веб-сайт/index.md`
- `CHANGELOG.md`
- публикациях в `publishing/`
