# Настройка Discord-сервера ZIP

## Шаг 1: Создание сервера

1. Откройте Discord
2. Создайте новый сервер «ZIP»
3. Иконка: логотип из `learning/соцсети/изображения/логотип.svg` (экспорт в PNG)

## Шаг 2: Каналы

Создайте категории и каналы по [README.md](README.md).

### Категория «Информация»

- `#объявления` (только админы могут писать)
- `#правила` (read-only)
- `#приветствие`
- `#роли` (с реакциями)

### Категория «Общение»

- `#общий`, `#помощь`, `#идеи`, `#покажи-проект`

### Категория «Разработка»

- `#компилятор`, `#stl`, `#ide`, `#документация`, `#pull-requests`

### Категория «Обучение»

- `#новички`, `#курс`, `#задачи`

### Категория «Интернациональное»

- `#english`, `#other-languages`

### Категория «Служебное»

- `#bot-commands`, `#mod-log`, `#встреча`

## Шаг 3: Роли

1. Настройки сервера → Роли
2. Создайте роли по таблице в README
3. Настройте цвета и права

## Шаг 4: Боты

### Welcome Bot

1. Пригласите MEE6 или Carl-bot
2. Настройте приветствие
3. Выдача роли «Новичок»

### GitHub Bot

1. Пригласите GitHub Bot / вебхук
2. Подключите `3537mari/zip`
3. Канал `#pull-requests` для уведомлений

## Шаг 5: Инвайт-ссылка

1. Настройки сервера → Приглашения
2. Создайте постоянную ссылку
3. Добавьте в README, сайт и `community/README.md`
