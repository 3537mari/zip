# Discord-сервер ZIP

## Структура каналов

### Информация

- `#объявления` — новости проекта (только админы)
- `#правила` — кодекс поведения
- `#приветствие` — представьтесь
- `#роли` — выбор ролей

### Общение

- `#общий` — общее обсуждение
- `#помощь` — вопросы по ZIP
- `#идеи` — предложения
- `#покажи-проект` — ваши проекты

### Разработка

- `#компилятор` — zipc, zip-vm
- `#stl` — стандартная библиотека
- `#ide` — LSP, плагины
- `#документация` — docs
- `#pull-requests` — PR updates (бот)

### Обучение

- `#новички` — вопросы от новичков
- `#курс` — обсуждение курса
- `#задачи` — задачи для практики

### Интернациональное

- `#english` — English discussion
- `#other-languages` — другие языки

### Служебное

- `#bot-commands` — команды ботов
- `#mod-log` — лог модерации
- `#встреча` — еженедельные встречи

## Роли

| Роль | Цвет | Права |
|------|------|-------|
| Админ | 🔴 | Все |
| Мейнтейнер | 🟠 | Управление каналами |
| Модератор | 🟡 | Мут, бан |
| Контрибьютор | 🟢 | Доступ к #dev-каналам |
| Участник | 🔵 | Обычные права |
| Новичок | ⚪ | Первые 7 дней |

## Боты

1. **Welcome Bot** — приветствие, роль «Новичок», ссылка на правила
2. **GitHub Bot** — issues/PR, синхронизация с репозиторием
3. **Stats Bot** — `/stats`, `/benchmarks` (опционально)

## Правила

1. Уважение — уважайте других участников
2. Онтопик — пишите в соответствующие каналы
3. Никакого спама — не флудите
4. Никакой рекламы — без разрешения админов
5. Помощь — помогайте новичкам
6. Языки — русский и английский приветствуются
7. Код — используйте блоки кода для примеров
8. NSFW — запрещено

Нарушение → мут/бан.
