# Telegram-бот ZIP

## Возможности

- `/start` — приветствие с ссылками
- `/docs` — документация
- `/install` — установка
- `/benchmarks` — бенчмарки
- `/faq` — частые вопросы
- `/help` — список команд

## Реализация

### Вариант 1: Python (aiogram)

```python
from aiogram import Bot, Dispatcher, types

bot = Bot(token="YOUR_TOKEN")
dp = Dispatcher(bot)

@dp.message_handler(commands=["start"])
async def start(message: types.Message):
    await message.answer(
        "Привет! Я бот ZIP.\n\n"
        "Ссылки:\n"
        "📖 /docs — документация\n"
        "💾 /install — установка\n"
        "⚡ /benchmarks — бенчмарки\n"
        "❓ /faq — вопросы\n"
    )
```

### Вариант 2: Rust (teloxide)

```rust
use teloxide::prelude::*;

#[tokio::main]
async fn main() {
    let bot = Bot::from_env();
    teloxide::repl(bot, |bot: Bot, msg: Message| async move {
        if msg.text() == Some("/start") {
            bot.send_message(msg.chat.id, "Привет! Я бот ZIP.").await?;
        }
        Ok(())
    })
    .await;
}
```

Токен — через BotFather; не коммитьте секреты в репозиторий.
