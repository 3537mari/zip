# Кодекс поведения сообщества ZIP

## Наши обязательства

Мы обязуемся сделать участие в проекте свободным от притеснений для
всех, независимо от возраста, телосложения, инвалидности, этнической
принадлежности, пола, опыта, национальности, расы, религии или
сексуальной идентичности.

## Стандарты

### Приемлемое поведение

- Уважительное общение
- Конструктивная критика
- Принятие конструктивной критики
- Фокус на том, что лучше для сообщества
- Эмпатия к другим участникам

### Неприемлемое поведение

- Оскорбления, унижения
- Троллинг, провокации
- Публичное или приватное преследование
- Публикация чужой личной информации без разрешения
- Другое непрофессиональное поведение

## Ответственность

Мейнтейнеры проекта отвечают за разъяснение стандартов и принимают
корректирующие меры в ответ на неприемлемое поведение.

## Область применения

Кодекс действует в:

- GitHub (issues, PR, discussions)
- Discord
- Telegram
- Других каналах проекта
