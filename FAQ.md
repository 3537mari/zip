# FAQ — Часто задаваемые вопросы о ZIP

## Общие

### Что такое ZIP?

ZIP — язык программирования на кириллице. Императивный потоковый,
с ИИ-примитивами и формальной верификацией.

### Почему на кириллице?

Уникальная лингвистическая архитектура, семантические корни,
суверенитет технологий.

### Насколько быстрый?

- ~40× быстрее Python (наш suite, см. [docs/БЕНЧМАРКИ.md](docs/БЕНЧМАРКИ.md))
- Конкурентен с Rust/Go в зависимости от задачи
- В JSON-парсинге в ряде замеров быстрее наивного Rust

### Как установить?

```bash
git clone https://github.com/3537mari/zip.git
cd zip
cargo build --release --manifest-path zipc/Cargo.toml
```

### Есть ли IDE-поддержка?

Да: VS Code, Neovim, Emacs (см. экосистему в репозитории).

## Технические

### Почему нет сборщика мусора?

ZIP использует Move-семантику (как Rust). Память освобождается
детерминированно.

### Что такое VSO?

Verb-Subject-Object — порядок слов в ZIP. Глагол идёт первым.

### Что такое PERFECT?

Состояние после `!`. Данные становятся неизменяемыми.

### Что такое хор `||`?

Параллельное выполнение. Легковесные потоки.
